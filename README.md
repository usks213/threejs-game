# ASH — SDF Voxel / Motion Trial

2026-10-04の最新指示を反映した一人称アクションの検証場。Voxelは内部の距離データであり、Minecraft式の立方体表示は行わない。モーションを中心にDark and Darkerを意識した重い近接戦を検証する。既存草原版はPR #3に保持し、今回のブランチは `feature/first-person-voxel-core` / PR #4。mainへの反映は本人のプレイOK後。

## 表現と編集

- 世界は疎なVoxelの符号付き距離サンプル。地形・曲面のヴォールト天井・廃墟・樹木・扉・補給箱をCSGでラスタライズし、著者形状を保持せずVoxelデータからMarching Tetrahedraで表面メッシュを生成する。勾配から滑らかな法線を作る。同一材質の軸平行な距離場では、同じ等値面を2三角形へまとめて描画負荷を減らす。
- 地形サンプル間隔0.25m、人体0.0625m、装備パーツ0.02–0.0625m。鑿は半径0.27m、強撃は0.5m内の材質耐久を削り、ゼロになったサンプルだけを除去する。変更箇所の4mチャンクと境界を実行中に再生成し、旧GPU形状を破棄する。
- 照準レイ・移動のカプセル当たり判定は同じ補間SDFを参照する。距離補間と抽出は同じ6四面体分割。グリッドDDAや立方体面は使わない。
- 敵と腕・武器・盾もVoxel SDFから生成したパーツを関節で動かす。人体の毎フレーム再メッシュ化はせず、剛体パーツの関節アニメーションを使う。戦闘用の頭/胴カプセルはその姿勢を近似する。
- 水は既存の1mに対し一辺0.125m（1/8、体積1/512）。6×6×1.5m、27,648の保存的水量セル。重力/側方移送/固体排除/量保存を行い、水面距離帯を再構築して滑らかなメッシュにする。液体表現は柱の最高水面の近似で、飛沫や独立した水滴は対象外。
- 物理スカイ、PBR、SH/IBL、露出、ブルーム、動的影、体積光、SSRを継承。松明で照らす暗い石造の試練場に変更した。反射面が視野にあり、固体に遮られていない場面でSSRを実行する。共有頂点と装備形状を再利用し、動的影は各フレーム1回だけ更新する。

## モーションと戦闘

斜め斬り → 返し斬り、頭上からの強撃。それぞれ予備動作・有効時間・振り抜き・回復までを連続Hermite曲線で作る。剣の長さは一定。肩/腰の捻り、重心、踏み込み、両腕の二骨IK、歩行を連動させる。柄と手を別々に振る方式は使わない。

描画と戦闘が同じ剣の軌道をサンプリングする。前フレームとの間を刃先移動3.5cm以下で補間し、刃が頭/胴に触れた瞬間だけ命中する。頭部補正、壁による遮蔽、命中/防御の短いヒットストップ、正面で上がった盾、ガード開始直後のパリィ、強撃の怯み、死亡時の倒れ込みを扱う。敵は斜め斬り/頭上斬りを予告し、後半に向きを固定して振り抜く。軽い攻撃で敵の振りを無限に中断できない。

移動には加減速、後退とガードの速度低下、攻撃中の移動/視点速度低下がある。硬直中は自由に連打できず、回復後半で次の一撃だけ予約できる。スタミナ、方向ステップ、ジャンプ、1.6秒の服薬（被弾で中断）、死亡と再挑戦も保持する。空気の斬撃音/金属の防御音/低い衝撃音を手続き生成する。アニメーションは手付けの手続き的試作で、モーションキャプチャや完成版のアセットではない。

## 属性・採取・制作

開始位置の左に木の丸太と草、右後ろに接続金属の実験台。剣・鑿で材質ごとに違う耐久を削るとSDFが欠け、同じ材質の素材が弾けて落ちる。近づくと回収する。画面左に素材数、照準下に耐久/燃焼/濡れ/帯電を表示。

- Fで火→水→土→風→雷を選択、Gで照準へ放つ。スマホは左上の元素・放つボタン。射程7m、スタミナ18、0.7秒の硬直
- 火は木/草へ延焼、水で消火と5秒の濡れ、土で鎮火と土/石への衝撃、風で風下へ火と落下素材を移動、雷は接続した金属へ減衰して伝わる
- 木材8を集めて、地面に照準を合わせBで作業台。Vで木壁（8）/木床（4）へ切替し、作業台の3m以内へ置く。スマホにも制作物・置くボタン
- 固体/キャラクターとの重複、支えのない空中設置、範囲外は素材を消費しない。破損建築は素材を返却しない（増殖防止）。設置累計64回まで。破損した扉/箱は開閉できない
- 空気は空領域、火は一時状態。水の永続流動は既存の閉じた水槽のみ。全世界の流体/熱力学/電磁気の再現、建築回転/スナップ、セーブは含まない

実装境界は[ADR0015](docs/adr/0015-elemental-survival.md)。

## 検証と範囲

Node22以上。`npm ci`, `npm run typecheck`, `npm run test`, `npm run build`。Playwright導入後 `npm run e2e` はビルド済みdistを使う。CIは検証済み同一SHAのPreview公開とPC/Android相当ブラウザ試験を独立実行する。

単体検証は抽出した曲面の頂点とSDFの一致、球状編集、曲面法線、モーションの位置/速度の連続性、一定の刃長、刃の経路外の非命中、壁遮蔽、ガード、スタミナ、水量保存を含む。ブラウザはPC/複数指スマホ入力、照準扉、回転停止、HDR例外、1/4速度での予備/有効/振り抜き/強撃の画像を採取する。`?test=1`の試験プローブは読み取り専用、F3は再メッシュ時間等の診断。

PC自動試験は実Pointer Lockと実マウスボタン/キー入力を使う。CDPがボタンイベントに付加する絶対座標由来の視点変化は相対MouseEventで補正し、視点操作も相対MouseEventで検証する。ゲーム状態を変更する試験専用APIはない。検証はSwiftShaderのソフトウェアGPUで、既存の解像度自動調整を低めの予算から開始し、動的影は512pxにする（通常GPUは1024px）。HDR機能は同じままである。OSの実マウスの手触り、実端末FPS、iPhone Safariは確認済みとは扱わない。24×30mのコア試験場で、セーブ/通信/大規模ストリーミング/大規模自由建築/木の剛体倒壊は対象外。水は閉じた近似流体で圧力/粘性/泳ぎ/浮力は未実装。Enshroudedのエンジンを再現したものとは主張しない。

## 敵と動く素材の元素反応（追加）

敵ごとに独立した布/金属の距離Voxelと耐久・燃焼・濡れ・帯電を保持する。火で布が削れ、濡れている間は燃えない。金属への雷は短時間の行動停止、濡れた敵への雷は増幅。火は近接する世界/敵へ視線を通して移る。風・土・強撃の力は敵の移動に反映され、SDF壁と他の体で止まる。死体からの素材は個体ごとの有限予算で一度だけ。碑による再挑戦でも予算を回復しない。

素材にも視線を合わせて属性を使える。木・草・布は燃焼し、水で消える。風で軽い素材ほど大きく飛び、重力・小さい反発・摩擦・水抵抗で止まる。水槽内では木などは浮き、金属や石は沈む。

敵の選択/材質場は人体近似SDF、近接判定は既存の関節カプセル。損傷箇所を関節メッシュへ局所転写し、滑らかな穴と状態色を表示する。完全な変形人体や全身剛体ラグドールではなく、武器/関節アニメーションを保持するための近似。地形・家・木全体の重力崩壊/剛体化は今回含まない。
