# EMBERFALL — 2D物理サバイバルクラフト

PR #6の独立したゲームです。砂崩れ、水流、燃焼が採掘と拠点づくりに影響します。採掘で材料を集め、作業台・たいまつ・拠点を工作し、石の堰で水を制御できます。死亡しても地形と持ち物を残して拠点へ復帰します。

この版は1536×768セルの連続世界、縦持ち用の素材・工作UI、材質別の2D照明・散乱光・ブルームを追加します。ゲーム候補9bc63292は170単体テストと13件のブラウザ経路を受入済みです（PC往復1再試行、3件の対象外profileを除外）。公開は最終コミットのCI・配信SHA照合で確定します。無限生成ではなく、遠方の物理を休止する有限予算の世界です。独自の名称・絵・地形を使用し、原作の完全再現とは称しません。

## 操作

スマホ: 左パッドで移動（上へ滑らせると浮遊）。画面または右の照準パッドで狙い、独立した「使う」ボタンで採掘・設置・射撃します。照準だけでは地形を壊しません。浮遊ボタンも併用できます。

PC: A/D移動、Space浮遊、マウス照準/左クリック使用、Xでも使用、3採掘・4石壁・5たいまつ、1/2杖、Tabメニュー。素材・工作・装備・画質はメニュー内です。設定で材質光・霧・ブルームとlow/balanced/highを切り替えられます。

## 開発・検証

Node.js 22以上。`npm ci`、`npm run typecheck`、`npm run test`、`npm run build`。公式Playwright Chromiumを用意して `npm run e2e`。CIではPC/Android相当の通常入力とPNGを検証します。実機FPSやSafariの保証とは区別します。

主実装は `src/emberfall/`、仕様は [生存工作](docs/emberfall/survival.md)、[広域世界と照明](docs/emberfall/open-world.md)、[残件](docs/emberfall/coverage.md)。旧遠征モードは `?mode=expedition` に隔離しています。

## 保存と公開

地形・設備・持ち物をこのブラウザへ保存します。旧生存保存は読み込み時には変更せず、初回の新形式保存時に原本も退避します。保存容量超過は表示し、最後の有効な保存を保持します。ブラウザのデータ削除には耐えられず、クラウド同期はありません。

PR #6は既存Workerの専用version previewで公開します。本番への切替はしません。公開manifestにコミットSHAを記録し、CIで候補と配信版を照合します。
