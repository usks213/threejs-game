# ASH — 七つの灯

Enshroudedの仕組みを参照しながら、独自の世界・名称・資産で作るブラウザ向けSDFサバイバルRPG。PR #4 / feature/first-person-voxel-core。既存草原版とネットワーク版は別ブランチ。mainへはマージしない。

## 要件一覧と現状

実装前に記録した[171件の公式資料付き参照要件](docs/reference/enshrouded-requirements.md)と[実装・受入台帳](docs/implementation-checklist.md)を正本とする。原作の全アイテム・全マップ・完成品の規模を複製したものではない。台帳で未実装/簡易/未検証を区別し、カタログ名だけを完成に数えない。

この変更は進行・保存・UIの大改変の検証中。まだ最終の通常プレイ一周、公開版チェックを全件完了したとは扱わない。

## ゲームの流れ

1. 開始地付近の丸太・岩を鑿で採集し、木材8/石6で灯守りの炉を点火。
2. 墓所の鍛冶師ナギを救出。炉の近くで武器/防具、登り鉤と風布の翼を制作・装備。
3. 霞の高台へ鉤縄で登り、霧の滞在時間に注意して結晶を回収。空中でジャンプを再入力すると滑空。
4. 墓所の銅殻の番人を倒し、結晶と火種で炉を強化。関門を開き尾根の野営地へ。
5. 七つの独自地域の探索印/資源を炉へ持ち帰り、次の地域を順に解放。洞窟、鉱山、湿地の祠、灰鈴城、雪の石堂、水没聖堂へ。
6. 最後の帰還鐘を持ち帰った後も、残る探索、生活設備、建築を続けられる。

原作の進行分類を参考にした独自の小規模な地域群。巨大な原作マップと同規模ではない。

## 操作

- WASD / 左スティックで移動、マウスPointer Lock / 右空間ドラッグで視点
- キーボード戦闘: Tで斬撃、Zを押している間は盾。左クリックと右ボタンの操作も従来どおり利用可能。
- キーボードだけの視点操作: Home / End で左右、PageUp / PageDown で上下。Shiftを併用すると通常の4%速度で精密操作（移動中のShiftは従来どおり走る）
- 左クリック / 斬撃、R / 強撃、右クリック長押し / 盾、Ctrl / 回避、Space / 跳躍
- E / 照準操作で箱・NPC・炉・アンカー。鉤縄は指定支柱だけ、滑空は装備後の空中ジャンプ
- F 属性切替、G 属性術、X 集中技（確定命中で100を貯める）
- I 所持品、J クエスト、M 地図、Tab 旅の記録。制作/装備/スキル/地図/拠点生活/設定を切替
- B 建築モード/設置、V 部品、F 回転、X 直前の未損傷建築を戻す、Delete 解体、G 建築終了。緑/赤の予告枠で置ける場所を確認。自作の扉はEで開閉。木の梯子は木材6で作り、正面/裏からEで掴む。W/S・左スティック前後で昇降、左右/E/跳躍で手を離す。壊れた梯子・天井・他の身体は通過しない
- 1 装備武器 / 2 装備道具（初期は鑿）、Q 回復薬、Esc 停止
- 設定でキー、感度、音量、描画品質を変更。スマホは48px以上のタッチボタン。横画面専用
- 移動/建築の失敗で閉じ込められた場合、地図の安全帰還を使用（素材25%を残す）

## システム

### SDFと元素
地形は距離Voxelから滑らかな等値面を生成。剣・鑿・元素で材質ごとの耐久を削り、同じ場を照準/衝突/再メッシュに使う。立方体面描画ではない。敵も独立した布/金属の材質場を持ち、燃焼・消火・濡れ・通電・局所損傷と、壁で止まる力を受ける。人体表示への損傷転写と関節カプセルは近似であり、完全変形人体/全身ラグドールではない。進行に必須の炉・NPC・宝箱・アンカーは耐久と延焼から保護し、照準UIに表示する。

### 制作・装備・生活
近接、弓と矢、杖と属性術。装備耐久/修理/強化/ジェム/解体、経験値/技能/再配分。食料と休息は時限強化。拠点収納、ゲーム時間で進む加工、種→作物→収穫、山羊の飼育/生産、家具の快適性。実際の制作条件と不足理由をUIに表示する。

救出後のナギ、木工師マキ、錬金師セナは実際の拠点内を歩き、昼の仕事・交流と夜の休息を切り替える。西方の帰還炉の近くでは、救出した2人に各木材6・布3の寝台を設置できる。屋根と実寝台、通れる経路が必要で、身体に重なる建築は拒否される。会話は現在位置で行い、生活動作から追加報酬は出ない。厳密な旧保存移行を含むCore試験は通過、公開PC/Androidの見た目の受入は残る。[NPC生活の範囲](docs/npc-daily-life.md)

### 収集図鑑
旅の記録の「収集図鑑」で、素材と品物の発見状態・地域・入手方法・用途を確認できる。初めて実際に手に入れた時点で自動登録し、登録では何も消費しない。使い切る・預ける・死亡する場合も発見記録は残る。名前や発見状態で検索・絞り込みできる。未発見の品物の詳細は伏せ、地図の未踏地点は解放しない。
古い保存には過去の取得履歴がないため、現在の持物・収納・装着済みジェム・回収待ち素材から確認できる分を引き継ぐ。以前に使い切った品は再入手時に記録する。PC/Android相当のブラウザ受入はCI待ち。

### 薄響の封庫（小さな任意ダンジョン）
開始地点の南東、座標(6.5, 9)の案内板から入る。入口左の鉱殻を鑿で削って薄響の鍵を取り、せり上がる三本歯の鳴動床を観察する。右の白い側道は安全で、停止梃子で罠を解除できる。奥の鍵差し開閉機に鍵を残すと、実際の吊り格子が上がる。封章箱から唯一の封章と経験値40を得て、同じ入口から戻る。鍵・停止・開通・報酬は保存され、死亡や再接続で増殖しない。
これは戦闘ボスや専用休憩所のない一室型の任意探索。基本世界・オンデマンド世界・西方世界の固定地形定義を変更せず、独立した実行時層を追加する。古い保存の建築/採掘や人物と重なると追加を見送り、旅の記録に理由を出す。通常Core経路は検証済み、PC/Androidの実画面受入はCI待ち。[設計・試験記録](docs/echo-vault-acceptance.md)

### 保存
ブラウザの ash-campaign-v1 に版番号/検査値付きで保存。持物、装備、技能、主副進行、拠点、世界のSDF差分とオブジェクト層、敵と報酬予算、元素状態、水槽、設定を対象とする。30秒ごと/停止時/重要操作後に保存。壊れた保存や未知の版は黙って消さない。全構成要素を検査してから適用し、途中で不正な内容が見つかっても元の状態を変更しない。直前の成功保存をバックアップする。新規開始・履歴復元は確認後に現行保存を別の不変履歴へ退避し、後の自動保存では履歴を上書きしない。設定の履歴一覧で保存先・日時・容量を確認して復元する。32履歴/容量不足/破損時には自動削除せず切替を止める。単独プレイのブラウザ内保存であり、クラウド同期ではない。

### 二人の共有遠征（公開受入中）
旅の記録の「協力プレイ」から部屋を作成し、招待URLを渡す。招待を開いただけでは参加せず、参加ボタンで接続する。参加前もゲストの元の保存や保存形式へアクセスせず、退出すると自分の保存形式へ戻る。ホストのブラウザが移動/衝突/戦闘/元素/持物を確定し、同行者は自分のHP・スタミナ・操作状態を持つ。世界・所持品・装備・進行はパーティー共有の簡易モデル。個人キャラクターの持ち込みは未実装。

建築/採掘/元素/収納の変更はホストの許可が必要。チャットは文字のみでミュート可能。ホスト切断中は同行者の世界を止め、復帰時に再同期する。ホストは旅を保存し、同行者の元の単独プレイ保存は変更しない。ホストがゲームを開いている必要があり、専用サーバーで常時動く世界ではない。PR5とは互換もルーム共有もない。

### 読み込みと描画
新規開始は拠点を先に生成し、周辺地域をWorkerで背景展開する。対応できない環境では処理を小分けにする。展開中の採掘/建築を保持し、完了前の遠方移動と保存を止める。近距離からメッシュを生成し、遠方の描画資源を解放する。CPU上の計測は実機FPSを保証しない。

標準は軽量な1パスPBR、空/影/環境光とSDF。高品質は既存のHDR・SSR・ブルーム・体積光。霧の危険・寒冷・酸素は色だけでなく文字で表示する。新しい湖は水面＋泳ぎ/酸素の近似で、既存の細粒度水槽とは別物。全世界の圧力流体/全建物の崩壊は含まない。

細粒度水槽はカメラ外で表示メッシュの再生成だけを延期し、視界へ戻ったフレームで現在の水面へ更新する。水面のFloat32高さと固体場が同一なら再生成を省く。見えている流水は従来の0.3シミュレーション秒超の更新間隔と同じSDF抽出を使用し、水量・落水・水車・保存は変更しない。F3の waterSurface に再生成回数/時間を表示する。画面内の流水の同期メッシュ生成とソフトウェアGPUの負荷は残り、実機FPS改善は未測定。

## 未完了を隠さない

原作規模の全コンテンツ、完全な流体/剛体崩壊等は台帳の対象外/未実装を参照。機能名があっても、通常操作から到達し試験を通るまで完了にしない。実装済みの範囲と、今後の範囲を分ける。

ブラウザE2EのPCキャンペーン経路は実キーによる視点操作を使う。CDPの絶対マウス移動はPointer Lockの相対移動を再現しないため、マウス専用の操作検証とは区別する。

### 標準配列ゲームパッド
左スティック移動、右スティック視点、A跳躍、B回避、X操作、Y属性/建築回転、RT斬撃、LT盾、RB属性術/建築終了、LB部材切替。左スティック押込で走る、右押込で道具切替。十字キー↑強撃/↓回復/→建築/←解体、View集中技/建築取消、Menu一時停止。RTは押すたびに1回攻撃し、押しっぱなしでは連射しない。
開始・一時停止画面も十字キー/左スティックで選択、A決定、B/Menu戻る。音量や選択肢は左右で変更する。文字入力はキーボードを使う。接続直後・再開後は一度スティックとボタンを離して有効化する。切断、ブラウザAPI未対応、入力欄の編集中はゲームパッド入力を中立化する。操作表は開始/一時停止画面の「ゲームパッド操作」で開く。

### 試験中の西方遠征と保存
`?streaming=1` は同じ世界をオンデマンドSDFへ移す明示的な選択。`?expedition=west` はさらに集落・二口坑・二つの荷道・帰還炉を持つ西方遠征へ移す選択です。旧v2/v3の原本と専用アーカイブを残し、v4を別スロットへ検証後に保存します。既存の採掘/建築と新地形が衝突する場合は移行を止めます。デフォルトの世界は自動変更しません。公開ブラウザの移行受入が済むまで試験扱いです。

### 雨・風と釣り
保存される世界時計で天候が変化します。雨は屋根のない近傍の敵、活動中の燃焼材、落下素材を濡らして消火します。風は滑空と素材の慣性へ作用します。活動範囲と屋根判定に上限のあるゲーム近似で、全世界の水循環ではありません。
葦糸の釣竿と練り餌を制作し、所持品の釣竿を選択。岸から深さ35cm以上の水面を狙い、E/タッチの操作で浮きを投げ、食いつきの合図で再び操作します。早い巻上げ・移動・道具切替で中断し、餌は戻りません。魚は炉で料理できます。協力中の釣り操作は現在ホストのみです。

### 視点と読みやすさ
設定・保存から一人称/三人称、三人称距離、説明文100〜125%、画面揺れ・被弾明滅の軽減を選べる。初回はOSの揺れ軽減設定を反映。三人称でも攻撃/採取の正本はプレイヤーの照準で、カメラはSDF壁の手前へ寄る。釣り中は一人称になる。移動の揺れ軽減は武器の命中軌道を変えない。新しい画面設定は実ブラウザ受入待ち。

### 西方の追加内容
設定・保存の「西方遠征を追加する」で現在の旅を保存し、明示確認後に移行する。旧形式原本と専用バックアップを残し、既存の編集と追加地形が重なる場合は中止する。移行した進行の旧形式への逆移行は非対応。尾根突破後、灯穂の野から琥珀枝の森を開き、西へ延びる道を探索する。協力参加中は追加できない。

### 保存を端末へ持ち出す
設定・保存の「最後の保存を端末へ書き出す」で、検証済みのJSONをダウンロードできる。履歴ごとの書出しも可能。保存ファイルを選ぶと、現在と同じ世界形式の12 MB以内の内容を検証し、確認後に取り込む。現在の有効な保存とバックアップは別の不変履歴に残す。クラウドへの送信はしない。ゲスト/協力中の取り込みはできない。
旧形式のファイルは地形全体を検証するため、選択・書出し後に数秒ほど画面操作が止まる場合がある。検証済みファイルの取込確定では同じ検証を繰り返さない。ブラウザのダウンロード/ファイル選択の実操作受入は未完。

履歴が32件になったら、整理したい1件の「書き出して履歴整理を確認」を選ぶ。JSONが端末にあることを確認し、チェック後に「選んだ履歴を完全に削除」で空きを作れる。現在の保存・復旧用バックアップ・最新履歴・移行用原本は保護する。取消・閉じる・タブ切替後は選び直しが必要。中断時の確認・復旧は履歴を自動削除しない。完全削除後は書き出したJSONからの取り込みが必要で、ゴミ箱やクラウド同期はない。復旧記録さえ書けない容量不足では安全に停止する。[範囲・試験・未検証事項](docs/save-history-cleanup-acceptance.md)。


### 身体と環境
近くで燃える木材や帯電した金属に触れると、プレイヤーと同行者も影響を受ける。水面・雨・触れている濡れた面で濡れると消火できる。織り鎧は長く燃え、鎖鎧は物理防御と引換えに重く通電しやすい。直接プレイヤーを狙う術はないが、共有の危険な地形は術者自身にも作用する。HUDは霧/酸素/炎上などの切迫した状態を優先し、全状態は所持品画面で確認できる。プレイヤー身体の部位Voxel破壊は実装していない。

協力通信はプレイヤー状態の追加に合わせてプロトコル2に更新。以前のページを開いたままの場合は、ホスト・同行者とも再読み込みしてから接続する。保存世界や既存ルームの所有者識別は消去しない。

### コントローラーの再割当
旅の記録 → 設定で、標準 Gamepad の 15 操作をボタン交換方式で変更できます。スティックの遊び・左右交換・上下反転も保存され、初期化できます。Start/Options の一時停止とメニューの A 決定・B 戻る・十字移動は固定です。変更や再接続後はボタンとスティックを一度離してください。物理コントローラー実機での受入は未実施です。

### 制作道具と部位装備

所持品から斧・つるはし・平削りの熊手・建築槌を独立して装備できます。斧は木、つるはしは石/金属に強く、熊手は土/草の高い面だけを削ります。槌は攻撃で配置、強撃で解体。成功時のみ素材・耐久を消費します。道具は装備画面で石を使って修理できます。初期の鑿と通常の建築操作は引き続き利用できます。

大剣は長い刃・遅い振り・強い怯み、短剣は短い刃・速い刺突です。大剣は盾と併用できません。頭/胴/脚/盾と護符・指輪の共用枠があり、布/金属による防御・速度・寒冷・感電の違いが実際のゲームへ反映されます。古い胴防具だけのセーブも読み込めます。[検証範囲と残課題](docs/equipment-tools-acceptance.md)。

### 水車の織機

炉を灯して地下聖堂の敵を片づけ、東の水槽の水門レバー脇へ。拠点生活から木材8・石4・金属2で固定水車を組み立て、草葉6を投入すると布2を織れる。隣の水門を開くと実際の落水で動き、閉じた後の残り水が落ちきると停止する。静水・満水・羽根の障害物では進まない。破損は木材4・石2で修理でき、投入済み素材は停止や保存後も保持する。加工と受取はホストが操作。閉じた局所水槽だけの仕組みで、世界全体の流体・自由な水路や排水設備はない。[試験範囲とブラウザ受入待ち](docs/watermill-acceptance.md)。
