# パーツ台帳とカスタマイズの実装範囲

基準日 **2026-10-25 / 日本向け TAKARA TOMY**。`public/beyblade-data/` の parts/products/combinations は公式ページ・パラメーター画像を調べて転記した事実データです。転載画像・メーカー製モデルは同梱しません。各行に出典URLを保持します。

**網羅完了とはしていません。** 一部の限定品・ランダムブースター内組合せ・一覧外景品が未確認です。未掲載または未転記の値はnull、質量・慣性・摩擦等の物理定数は全行nullです。「発売済み」は公式発売日が基準日以前という意味で、現在の店頭在庫・継続販売を保証しません。発売予定品は製品一覧で識別し、対戦対象にしません。

## 構造
- 通常BX/UX: blade + ratchet + bit。
- CX: 公表済みの組立ブレードを選ぶと、出典にある lock chip / main blade / assist blade、または2026構成 lock chip / metal blade / over blade / assist blade をセットします。個別部品の数値に組立ブレードの値を配賦しません。
- CXの未確認の自由組合せは、安全側で未対応です。各構成部品の互換性・数値を追加検証した後に拡張します。現在は確認済み組立プリセットから選び、ラチェット・ビットを交換できます。
- ラチェット一体型ブレードは別のratchetやラチェット一体型bitと併用不可。一体型bitは別ratchetを持ちません。
- クロックミラージュはシンプルラチェット必須。確認済みシンプル型 (M-85,9-65,7-55,4-55) 使用時はビットのバースト耐性30、DSは20をモデル入力に使用します。
- 2-60は左回転16/8/6、右回転10/13/7という公式条件別値を保持し、無条件の値はnullのままです。
- モード別公表値は個別に保持します。自動変形する実機ギミックそのものの再現は未校正で、固定モードの近似です。
- 3on3重複確認は色・メタルコート違いと同一部品のモードを正規化。通常CXロックチップの重複は許可、ワルキューレ・エンペラーは例外です。

## 物理モデルとの分離

`profileFor` の質量0.035kg、半径0.024m、ギア半径0.006m等は**実測に基づかないゲーム設計値**です。公式の相対指標をSI単位に変換したものではありません。攻撃・持久・防御・ビット評価は公開された相対値から摩擦・反発・ロック閾値等のゲーム係数を調整しますが、その対応関係も未校正です。実機の勝率・軌道・接触音・Xダッシュ位置・分離挙動の同等性は主張しません。

左回転は画像で確認したコバルトドラグーン、ラスタードラグーン、ライトニングエルドラゴ、メテオドラグーンに設定。その他は右回転モデル既定値で、`spinVerification=unverified_model_default` として、全商品の回転方向を確認済みとはしません。
