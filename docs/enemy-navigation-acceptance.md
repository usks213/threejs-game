# 敵の局所移動（B12）

地域敵・西方の地域型敵・通常番兵・召喚眷属の移動方向を、実際のSDF地形に支持された共通の局所経路へ変換する。キャンペーンでは最後に見た位置、巡回先、帰還先を使い、視覚コントローラと経路器を分ける。射手の近距離後退も維持する。

- 0.4m間隔、左右前後3.6m以内、最大64展開・400支持点の局所探索。各支持点は最大5本の短い下向きレイと身体カプセル。経路探索は最短0.75秒間隔、通常の前方安全確認は0.15秒間隔で保持する。方向変更と地形revision変更では安全確認をやり直す。セル全件や世界全域の走査は追加しない。
- 木や低い壁を回る経路を保持し、同じ経路の節点を順に進む。辺の途中も0.25m以下の間隔で検査し、角抜けを拒否。足元5点の支持、段差0.26m・下り0.42m以内、頭上を含む身体空間を確認する。
- 実際の変位が小さい状態が2.5秒、目標へ近づかない状態が8秒続くと追跡をやめて帰還。帰還できない場合は安全な現位置で3秒待って再試行。帰還時にHP、敵の生死、報酬、所持品を更新しない。座標の直接変更や帰還テレポートはない。
- 突進は予告した方向を変えず、壁・崖・支持のない隙間では止まる。予兆、射撃の遮蔽、攻撃フェーズ、最終的な地形・身体衝突は既存の戦術とCore.moveが担当する。
- 経路は保存しない一時状態。保存復元後は再構築する。通常番兵・召喚眷属にも同じ経路器を使い、従来の視認・警戒と刃の連続軌道・予兆・攻撃フェーズは保持する。近接攻撃の足運びも支持を検査し、崖を越える移動だけを止める。倒れた召喚枠の再利用では実際の新しい出現位置を帰還先にし、以前の経路を持ち越さない。

## 検証

`tests/unit/enemy-navigation.test.ts` の12件で、実Core.tick/move/settleによる壁迂回、木の脇の狭い通路、崖越しの到達不能目標からの帰還、0.25m段差、壁/隙間拒否、実際の突進予兆と崖停止、他の身体による停止、頭上の到達不能目標、空地/失敗経路のキャッシュ、地形変更、予兆中の静止を検査。負傷済みの敵のHPと報酬台帳、落下しないこと、SDF非重複を確認する。

既存の戦術・通常番兵の視覚・敵元素・保存復元を含む55件、型検査、ビルドが通過。素材・HP・座標の付与なしの七地域Core操作経路（80.6秒）と西方の通常経路（51秒）も通過した。槍の間合い内への盾接近、坑道の入口で動いてきた番兵への対処、突進の回避、予兆中に詠唱を待つ操作を使う。最後の地域では実際に草葉を12追加採集し、包帯を4個追加制作する。テストの段数/時間/HPの上限や最終の保存・全印・死亡0の判定は緩めていない。別変更との統合後の全体結果は実装台帳へ記録する。

`tests/unit/ordinary-enemy-navigation.test.ts` の7件で、通常番兵と召喚眷属の実Coreによる木の迂回、崖越し追跡からの帰還、閉塞した帰還先に無限に押し続けず待つ動作、高所の到達不能目標、攻撃フェーズを維持した崖際の足運びを追加検査する。初章と弓/杖の通常操作経路も再確認する。

ローカルChromiumは既知のsocket EPERMで起動できないため、この変更ではブラウザを実行していない。PC/Android公開画面の経路・見た目・実機FPSは未検証。局所格子に収まらない大迷路、任意幅/位置の通路、飛行用3D探索、動く身体を迂回する群集経路、全世界navmeshを実装したとは扱わない。
