# 持物の枠・指定数収納・落とし物の受入範囲

対象: C05 / C11 / C12 / U05。数量の正本は既存の材料・アイテム台帳。

## 実装

- 持物は96枠。各枠は品目IDと数量だけを持つ表示配置で、別のアイテム個体を生成しない。指定数の分割・結合・空き枠への移動、同種をまとめる種類順の整理に対応する。
- 制作・使用・採集・展示で台帳が変わった場合、枠内の数を正本へ再調整する。分割で96枠を埋めた状態で別種の採集・制作報酬を受け取った場合は、自動で同種をまとめる。枠整理で材料や報酬を消去しない。重さの仕組みは追加しない。
- 手動で落とした品は最大32包の専用メッシュで地面に表示する。重力とSDF地形で落下・停止する。数を指定した回収、照準を合わせた操作による全数回収に対応。壁越し、遠距離、所持数上限、新しい品種の空き枠不足を拒否する。包が上限の場合は落とす前に中止する。
- 落とし物は消滅時間を持たず、数量・位置・落下速度を保存する。地形編集で埋まった包は保持し、遮蔽物を除くまで回収を許可しない。下方へ12m落下した場合は元の配置点へ戻すため、無限落下で数量を失わない。
- 装備・釣竿・重要品を落とすことと通常収納へ預けることは拒否する。展示可能な装備は素材費を払って作る既存の記念展示台で保管する。展示台の耐久・強化・ジェムの預かり状態と、展示中の1個の予約を維持する。
- 拠点収納は合計500個。材料に加えて食料・薬草・矢・種・通常素材を指定数だけ預ける／取り出す。操作範囲は点火済みの炉の4m以内。制作は手持ちの材料だけを使うことを画面で説明する。
- 「収納と同じ素材・消耗品をまとめて預ける」は、既に収納内にある種類だけに統合する。別種・装備・重要品を動かさず、合計容量が不足した場合はすべて移動前に中止する。既存の材料一括収納ボタンも維持する。
- アイテム詳細に分類・効果・入手経路、選んだ装備と現在の装備の数値比較、耐久・強化・ジェムを表示する。比較値は実際のCampaignSystemの補正値を使い、上位ジェムや技能の定義を複製しない。
- 枠操作と指定数収納は共有台帳の版を照合し、同じ古い操作を再送しても二重に移動しない。収納は同行者の変更許可をホストが再確認する。ゲストは要求のみ送り、自分の単独保存へ書かない。
- 旧セーブの配置がない場合は数量を変えずに配置を作る。新しい保存の不正な枠・包・重複ID・範囲外位置・不正数・疎な配列は、世界や台帳を変更する前に拒否する。

## 確認

`tests/unit/inventory-stacks.test.ts` は満杯、分割、結合、移動、整理、消費後の再調整、指定数の回収、二重操作、上限、遮蔽、重要品保護、不正保存を検証する。

`tests/unit/inventory-storage.test.ts` は材料／食料／薬草／矢の指定数移動、既存種類だけの一括収納、満杯での全取消、展示予約、装備保護、共有操作、原子的な保存復元を検証する。

`tests/unit/inventory-normal-play.test.ts` は新規・無所持から本番の移動・照準・採掘・炉点火・調理・矢制作・栽培を行い、その実物だけで分割、収納、物理回収、セーブ／再読込を検証する。

既存の展示、キャンペーン保存、ネットワーク保存、バルク制作、死亡時の操作拒否も含む重点試験135件が通過。型検査を通過。PC/Android相当は `tests/e2e/campaign-inventory-stacks.spec.ts` の各2件（計4件）を定義し、テスト一覧で検出を確認。

ブラウザの実行・画面確認は対象コミットのCI待ち。ローカル環境の既知のChromium起動制限のため実行していない。実機Android/iPhoneの確認済みとは扱わない。
