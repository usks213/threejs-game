# 実装台帳

2026-10-04。仕様正本は `voxel-coop-adventure-spec.md`。これは途中の実装記録であり、全仕様完成を意味しません。

## M0: 共有サーバー基盤
- 実装: 同じゲームルールを使うCloudflare Durable Object権威、4人上限（4人品質未確認）、SQLite checkpoint、独立ルーム、新規接続、差分地形、全再同期、クライアント再接続、action IDの重複排除と保存後ACK。
- 修正: 共有Dropの削除伝播、Drop物理を人数分進めない、遠隔Host位置の誤表示、入力停止timeout、初参加者の個人状態分離、不正action検証。
- ローカル合格: 実WebSocket2クライアントで移動、同一Drop拾得競合、再送、地形編集、再同期、退出/再参加、サーバーを停止してから保存復帰。既存8実Colyseus接続の回帰も合格。
- 合格: 型検査、301単体/実接続テスト（53ファイル）。
- 未検証: 公開Durable Object接続、独立2ブラウザ、切断復帰の画面操作、150ms/損失条件、4人の実機負荷。
- ローカルChromiumはプロセスsocket制限で起動できないため合格扱いしない。GitHub CIに独立2ブラウザと公開先試験を設定。
- セッションIDは部屋内の復帰識別のみ。個人アカウント認証は未実装。招待リンクを持つ人が参加できる小規模協力用。
