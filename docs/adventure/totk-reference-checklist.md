# 参考作品の機能分類と調査境界

調査日: 2026-10-04。対象: Nintendo公式の『ゼルダの伝説 ティアーズ オブ ザ キングダム』紹介・攻略・開発者インタビュー。これは機能カテゴリを整理した設計資料であり、全アイテム、全敵、全クエスト、全数値の完全データベースではない。公開資料だけで「すべて」を検証したとは主張しない。

記号: **確認** = 下記一次資料が機能を説明。**追加確認** = 設計上落とせない調査項目だが今回の取得資料では詳細未検証。**独自** = 新作向けの設計提案。実装済みを意味しない。

## 1. 世界・探索
- **確認 [S1]**: 空の島、地表、地下という高さ方向の異なる探索領域。街・洞窟・大穴などのロケーション。進路選択の自由。
- **確認 [S5]**: 洞窟の発見と踏破記録、地下の暗さを解決する光源、地下探索と地上探索を関連づける発見。
- **追加確認**: 各バイオーム、天候・時間帯の網羅、井戸、地形配置、世界更新周期、遠景ストリーミングの細則。
- **新作への抽出**: 垂直な地形を見て行き先を決め、道具を組み合わせて移動し、別の高さの領域で得た資源を持ち帰る。

## 2. 基本移動・乗り物
- **確認 [S3,S4]**: 滑空、登れる面と滑る面、騎乗、牽引、飛行装置。
- **追加確認**: 歩行/走行/跳躍/しゃがみ/泳ぎ/潜行の操作・判定詳細、落下・着地・盾移動、上昇気流、搭乗中の衝突。
- **新作への抽出**: 地形、スタミナ、道具の選択がルートを変える。移動入力・カメラ・着地の気持ちよさを基盤にする。

## 3. 特殊能力・創作
- **確認 [S2]**: 物体をつかみ移動・回転・接着する。武器・盾・矢に素材を組み合わせて性質を変える。物体の動きを逆再生する。頭上の固体を通過する。
- **確認 [S3]**: 構造物の再生成能力、合成解除、操作対象の視覚的な識別。
- **新作への抽出**: 物体グラフ編集、装備レシピ、有限の物体履歴、検証付き垂直移動、設計図。固有名・見た目・演出は新規制作。

## 4. 物理・装置・環境反応
- **確認 [S4,S5]**: 交換で装置を得る、動力容量の拡張、車輪や放炎装置の組合せ、属性素材の効果。
- **確認 [S6]**: 高低差を連続した世界として扱う開発上の狙い。環境ごとに特色の異なるダンジョン。
- **追加確認**: 剛体、浮力、摩擦、質量、関節、風、燃焼、熱、電気、濡れ、凍結、爆発の全組合せと内部実装。公式宣伝から特定の物理エンジンや数式を断定しない。
- **新作への抽出**: 装置を単体の台本ではなく共通ルールで組み合わせる。見た目と衝突・材質・質量に矛盾を作らない。

## 5. 資源・装備・生活
- **確認 [S3]**: 採集、食材、料理と効果、レシピ記録、武器耐久、装備強化、持ち物容量、素材売却、体力/スタミナ拡張。
- **確認 [S4]**: 装備合成の分解、動物との関係、収集記録、装置供給。
- **追加確認**: 全レシピ、通貨体系、買戻し、素材再出現、住居、染色、詳細な耐久式。
- **新作への抽出**: 探索→採集→加工→移動/戦闘の選択肢増加という循環。合成前に効果と消費を見せる。

## 6. 戦闘・敵・ボス
- **確認 [S4]**: 溜め攻撃、回避からの反撃、空中射撃、盾受けのタイミング、投擲素材による妨害。
- **確認 [S5]**: 大型敵の弱点に移動能力を使う、属性装備、機械を使った攻撃、特殊な被害からの回復。
- **追加確認**: 敵/ボス全種類、武器別コンボ、追跡・索敵・連携、敵の世界スケーリング、部位ダメージ、味方能力、最終戦の全段階。
- **新作への抽出**: 読める予兆、避けられる攻撃、物理・属性・移動の複数解。単なるHP増大ではない役割差。

## 7. 謎解き・進行・物語
- **確認 [S3]**: 小規模な能力試練、自由な地域攻略、冒険記録と目標表示、会話から得る目的、探索報酬。
- **確認 [S6]**: 地域の特徴を活かした大規模なダンジョン。
- **追加確認**: 全メイン/サイド依頼、仲間、記憶、ミニゲーム、収集、運搬、復興、終盤条件、クリア後状態。
- **新作への抽出**: 試す→理解する→応用する。協力必須の課題だけで埋めず、人数が減っても詰まない解法を用意する。

## 8. UI・カメラ・地図
- **確認 [S3,S4]**: 目標ログ、地図ピン、持ち物整理、図鑑的な記録、探索支援。
- **追加確認**: カメラ衝突、ロックオン遷移、照準、装備ショートカット、全設定、言語/字幕/入力支援、手動/自動保存の厳密な仕様。
- **新作への抽出**: 状態を隠さないHUD、色以外の対象識別、キー変更、低動揺モード、読みやすい字幕、保存成功/失敗表示。

## 9. グラフィック・音・プレゼンテーション
- **確認 [S7]**: 環境音の距離感を表現する音響への注力。
- **追加確認**: シェーダー、LOD、照明、ポスト処理、音楽状態遷移、音響伝播の内部方式。
- **新作への抽出**: 独自の色彩設計・シルエット・空気遠近・昼夜・風・環境音。原作の素材、旋律、キャラクター、地形、紋章、文章、UI画像は転用しない。

## 10. マルチプレイは追加設計
本調査の参考作品の機能をマルチの仕様だと扱わない。接続、状態同期、競合、権限、荒らし防止、再接続、協力の報酬、共有セーブは新作が独自に設計・検証する事項。単独プレイの時間停止を、そのまま共有世界に持ち込まない。
