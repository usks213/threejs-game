# 冒険の進行・地域の記録・次の航路

対象: QUEST-01 / QUEST-03 / QUEST-05 / QUEST-06 / QUEST-07。ITEM-01 の採集・採鉱・食材・銀貨・所有権付きドロップ・スタック上限は既存実装を維持する。

## 実装する有限の内容

- 出発の実地練習: 移動6m → 地形採掘 → 共有ドロップ拾得 → 部品接着 → 協力救助。権威側で成功した行動を順に記録する。実プレイヤーの救助に加え、X3/Z12の練習人形で一人でも3秒の救助を練習できる。離れる・被弾する・キャンセルすると途中の秒数は破棄する。
- 地域拠点: 既存の輸送・救助・復旧の3部屋に、往来の回廊・選択の機関室・上の書架を加え、3地域×6部屋。入口、側道、外階段、屋根、掘削、自作足場を利用できる。有限の探索拠点であり、大規模な商用作品と同じ面積・部屋数・物量を主張しない。
- 別棟の依頼: 各案内人から受け、3枚ずつの独自文章を実際に調べて写す。地域の物理解は、荷の重量、金属へ水を流す、軌跡戻しした部品の運搬。各機関室には電池と灯具を使う別解もある。条件は0.5秒保持し、成功は共有保存へ一度だけ記録する。
- 発見と報酬: 9枚の記録は個人の図鑑。地域報告の銀貨12枚はワールドで一度だけ地面に現れる。新規参加者へ同じ銀貨を再発行しない。後から来た人も記録を調べて自分の装飾を解放できる。
- 拠点装飾: 荷守りの航路旗、洞海の音碑、記録庭の風飾り、三層の帰還碑。独自の0.125mボクセル形状を持ち、通常の設置・衝突・採掘・素材消費・所有権・保存を利用する。解放は権威側で再検証する。
- 終幕後: 嵐心討伐後、案内人に木材8・石6・結晶3を届ける別々の新航路依頼。各依頼は共有で一度だけ素材を消費して銀貨20枚を地面へ置く。3地域分の完了で帰還碑が全員に解放される。既存の自由探索・競走・建築も続けられる。
- 次の航路: 個人ワールドの設定に専用の確認を設ける。現在の最新checkpointを保存し、旧ワールド・持ち物・地形を復旧用記録へ保護してから原子的に置き換える。保護や保存に失敗した場合は現ワールドを継続する。地形・持ち物・依頼をリセットし、記録の図鑑・地域装飾の解放・前周の競走最高記録は残す。周回ごとに必要重量12/18/24、回路の灯具1/2、出発時刻が変わる。地形seed自体は既存の独自固定seedを維持する。
- 共有ワールドからローカルの周回操作はできない。共有の世界や他参加者をリセットする管理機能として扱わない。

## 既存実装と互換性

QUEST-05のHP/スタミナ/電池/所持枠成長、道標移動、動く収納、動く寝床は既に実装済み。重複実装しない。成長は共有の達成数から導出するため、後参加でも追いつける。

旧セーブのメイン依頼・地形編集・私有建築を保持する。別棟は一度だけ配置し、既存の編集・建築・物理部品・木がある場所は配置を省略する。壊された部屋を再ロードで勝手に復元しない。旧セーブで記録が地形や建築に埋まっていた場合は、案内人の「閲覧場所を復旧」から、埋まった記録のみを入口の空いた場所へ移せる。プレイヤーの地形・建築は消さない。機関室の中央の設置範囲と記録の保護範囲は離して配置する。新しい地域・個人の保存フィールドは任意フィールドとして導入し、範囲・重複・参照整合を検証する。
