# 協力プレイの入力・開始地点・ブラウザ受入修正（2026-10-05）

## 確認した不具合

Actions [37283595515](https://github.com/usks213/threejs-game/actions/runs/37283595515) の公開2ブラウザ検証で、参加者は接続済みでも操作開始前に敵の攻撃を受けていた。公開版のトレースでは2人目のHPが25→7→5となり、Dキー押下後に0となった。描画・RAF間隔は最大約7.4秒で、入力送信も描画待ちになっていた。

ローカルサーバーの2ブラウザ検証では移動が成功した後、2人目のX座標が1.6から5.0まで進み、開始地点の木材が3mの拾得範囲外となった。また再試行時はPlaywrightの自動トレースと手動トレースが競合していた。

## 変更

- 移動キーの押下・解放時に直ちに入力を送信する。100msの入力更新を描画とは別に行い、保持中の操作をサーバーの無入力タイムアウト前に更新する。ジャンプも押下時に送信する。
- メニュー、フォーカス変更、非表示、blur、回転時は移動入力を解除する。読み込み中は見えない移動を送らない。協力接続でも送信入力を診断値へ記録する。
- Generator4の地表開始地点（X=0、Z=8）から半径6m、生成地表の高さ−2m〜+4mを普通の敵の対象選択・侵入から除く。過去の保存で中にいる敵は外へ退避できる。一般的な無敵、世界の一時停止、地底・空・任意の拠点の安全化は追加していない。発射済みの飛び道具や環境ダメージの一般規則も変えていない。
- 共有物資の同時回収を移動より先に検証する。移動では観察側が受信した正本座標を見てキーを解放し、操作側の座標、向き、ジャンプも従来どおり確認する。
- 2ブラウザのトレースをテスト側で一元管理し、失敗した試行ごとに保存する。失敗時にはHP・スタミナも記録する。
