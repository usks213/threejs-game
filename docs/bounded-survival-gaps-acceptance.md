# F11 / E11 / H01 / B19 の限定補完

## F11: 最後に受けた通常近接攻撃の原因

通常番兵の刃が身体へ命中してHPを減らした時点で、原因を「敵の攻撃」へ更新する。実際の炎上ダメージを受け、消火後に番兵の刃で死亡する回帰を追加。パリィでは原因を上書きせず、復活で消去する。既存の死亡袋・二重ドロップ・安全地面選定は保持する。

## E11: 寒冷地域へ入る前の警告

実際の寒冷地域の水平境界から4m以内で「寒冷地域が近い」を表示する。内部では蓄積が0でも寒冷地域と分かる。保温装備・食事・火と退域回復を案内し、切迫した霧・酸素・炎上・感電・寒冷は優先する。未発見地域名や地図は開示しない。寒冷の蓄積・軽減・回復の数値は変更しない。

## H01: 建築範囲と復活先

建築・盛土が共通で使う半径を `flameBuildRadius` に集約する。未点火0m、点火後は `10 + 炉段階 × 3` m **未満**。拠点生活に固定炉の点火条件、現在の有効な中心、範囲拡大、霧の猶予、実際の復活基準点を表示する。点火・炉強化の結果にも建築半径と霧猶予の変化を別々に表示する。

建築の中心は従来どおり谷の炉・発見した地域炉・解放した西方炉。尾根の野営地は復活先であり、今回建築中心へ追加しない。復活先は谷の炉から尾根の野営地点火で切り替わる。地域炉への地図移動では切り替わらず、塞がれた地点では既存の安全地面探索・開始地側退避を使う。

## B19: 装備レベル・品質・強化・追加効果

制作する品ごとに固定されたレベルと品質を、保存された耐久・強化・ジェムとは別の正本カタログに持つ。装備レベルは同じ型の基礎性能の段階で、人物レベルによる装備制限ではない。ランダムな戦利品や新しい保存フィールドは追加しない。

- 武器・採集道具の基礎倍率: `1 + (装備Lv − 1) × 0.1 + 精製品質の0.2`。対象外の攻撃種には倍率を加えない。
- 防具の基礎軽減: `部位基準 × (1 + (装備Lv − 1) × 0.1 + 精製品質の0.4)`。
- 銅風の剣はLv2・精製で物理1.3倍、灯木の杖はLv1・精製で属性1.2倍、調律杖はLv3・精製で属性1.4倍。
- 布防具はLv1・標準、銅防具はLv2・精製。胴20→30%、頭8→12%、脚10→15%という既存値を維持する。大剣・短剣・弓はLv1・標準で、それぞれの既存の型の威力・動作を使う。
- 強化は武器/道具の威力を段階ごとに10%、防具の軽減を3ポイント加算。ジェムは既存の段階別効果を別に加算。破損時は従来の50%補正。

丸めた正本の基礎値を実際の戦闘が使うため、`0.20 × 1.5` の浮動小数誤差で既存の厳密な比較を変えない。制作・持物・装備欄でレベルと品質を表示し、持物比較には実際の装備後の攻防、独立した強化と追加ジェム効果を表示する。通常攻撃の基礎値は実際の命中時の丸めに合わせ、弓は実際の小数ダメージを保つ。
