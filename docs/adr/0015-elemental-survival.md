# 0015: 材質耐久・属性・収集と小規模建築

2026-10-04、PR #4追加指示。距離Voxel→SDF等値面→滑らかなメッシュという0014の方式、刃の軌道を正本とする近接戦闘を維持する。立方体面描画には戻さない。

## 世界の正本と材質

占有サンプルには材質による耐久値を遅延割当する。土24、石90、木45、加工木50、金属120、草12、碑石100。剣/鑿/敵の刃が共有SDFへ接触したときだけ範囲内サンプルの耐久を減らす。鑿も耐久を無視して球状CSGを消去しない。ゼロになったサンプルだけ正の距離へ書き換え、同じ場から再メッシュ・照準・衝突を更新する。正の補間用サンプルからは資源を生成しない。重なる著者レイヤーは所有レイヤーだけを掘り、下の材質と耐久を保持する。

一回の枯渇につき同材質の1単位が出る。生成ドロップを一度だけ収集システムへ渡し、丸みのある破片と回収可能な素材として描く。加工木は木材、碑石は石、地面は土の素材へまとめる。破損扉/箱の形状を開閉操作で再生成させない。未破損時の既存インタラクトは維持する。

## 局所属性の近似

固定0.1秒刻み、最大256の活動状態、64の一時効果・64の破壊破片。火は燃える材質へ6近傍で広がり毎秒15ダメージ、水は消火して5秒濡らす。既存水槽の水面下も消火する。土は消火と土/石への衝撃、風は風下1.5m以内への着火伝播と見える落下素材の移動。雷は6近傍で接続する金属のみ、最大64ノード・減衰付きで伝わり時間で消える。属性術はスタミナ18と0.7秒の硬直を使い、射程7m、遮蔽を守る。

空気は未占有領域、火は活動状態、水は既存の閉じた0.125m有限体積水槽と一時的な濡れ表現である。世界全域を満たす流体、酸素/煙/圧力/温度/湿度の保存則や完全な電磁気学は扱わない。水の術は水槽外に永続的な水たまりを生成しない。追加版では敵の独立材質Voxelにも作用する（READMEの敵/動く素材節）。プレイヤー火傷は対象外。

## 収集と制作

192個までの描画・落下処理を行う。超過資源は元位置を持つ待機列に保持し、プレイヤー付近を固定サイズの走査で優先する。上限に達しても素材を消去しない。視線と距離を満たした素材を接近回収し、遮蔽越し・固体内部の回収を拒否する。ドロップは重力方向に落ち、SDF表面で止まる。

木材8で作業台、作業台3m以内で木壁8・木床4。設置は地面への照準、距離、視線、四隅の支持、固体/体との重複を検証し、成功後だけ消費する。建築は角を丸めたSDFとして通常の材質・衝突・燃焼を使う。建築由来サンプルは資源を出さないため、少数の木材から多数の距離サンプルへ変換して再採掘する増殖を防ぐ。この試作では建築の回収/解体返却・回転/スナップはない。レイヤー数を確実に制限するため制作は1セッション累計64回。セーブ・協力通信は引き続き対象外。

## 検証

材質/重なり/再採掘、火の拡散・消火・濡れ、実レイからの金属通電・減衰、活動数上限、収集の重複/遮蔽/超過時保存/優先化、落下/風、設置の原子性・作業台条件を単体で検証する。CoreSimulationの実Actionとtickを通じた攻撃→破壊→回収→作業台、属性術と硬直、遮蔽、破損扉の再生成防止を検証する。PC/Android相当E2Eでは本番入力から発火/消火/採取/作業台作成とモバイル48px領域を確認する。ブラウザ結果は対象SHAのCIで確認し、実機性能は別途扱う。
