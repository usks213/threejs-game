# ADR 0003: スマホ同時入力と岩・水の操作

2026-10-03、採用。スマホで操作を一通り試せるレビューを先に届ける。

ジャンプとツールは接触時に発動し、二本指でも互換クリックへ依存しない。キーボード/支援技術のクリックだけを別途処理し、二重発動を避ける。CharacterMotorは入力保持150ms・接地猶予100msを持つ。

カメラは垂直までOrbitを許可。上方向をOrbitに直交させ、極でのLookAt不安定を防ぐ。地形のRaycastで距離を短縮し、画面から戻せるボタンを設ける。

岩は最大12球のペア接触とプレイヤーカプセル接触を追加。球体判定の距離をSDF勾配で補正。角運動量・任意形状・建物崩壊は対象外。Rapier等との比較は未完了で、物理エンジン選定を確定したとは扱わない。

水は最大384セルの容量移送を継続。保守的な床高・最小膜厚・水位差により落下と横移動を扱う。盛土は水を隣/上へ移し、行き場のない水は保持。地形編集で床キャッシュを無効化する。表示は内部面を省いた単一の動的BufferGeometry、再使用する固定サイズBuffer、10Hz更新。泳ぎ/浮力/海洋の解決とは扱わない。

保存形式version1、generator1、seed7319を維持。旧セルを読込時に切り捨てず保持して新しい流体処理へ渡す。床高は派生表示情報で保存の必須項目に加えない。
