# ADR 0002: 地形と接地の最初の改善

2026-10-03、採用。高速なスマホレビューのため、異LODのTransition Meshを一度に実装せず、既存の有限Streaming範囲を1m格子に統一する。表示範囲・編集上限は増やさず、Geometry資源の解放も維持する。CPU初期生成の増加を許容して、今回は境界の連続性を優先する。異LOD方式の比較は後続。

Meshの交点は非線形密度場で反復補正し、接続するBrick間で同じ交点を作る。地形編集は局所Brickの一括反映とする。

プレイヤー用のCharacterMotorを描画から分離。5点で近似した直立カプセルを3分割の移動で解決し、斜面・低い段差・壁・天井を扱う。CSG境界の平均勾配で空間を過大評価しない。厳密な連続衝突判定やRapier等の比較を完了したとは扱わない。岩/流体は今回の改善対象外。

保存データの位置・編集形式を維持し、旧データも新しい接地で安定化する。レビュー時は変更点、重点操作、未完成と既知の問題を必ず示す。

Nodeで現在の起動範囲を一回計測：800 Brick、128 draw用Mesh、56,083三角形、Geometry 1,822,548 bytes、生成356ms。スマホのFPSや生成時間の保証ではない。
