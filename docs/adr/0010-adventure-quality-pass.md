# 0010 探索・建築・描画をつなぐ品質改善

## 参考と方針
ユーザー指定：Valheim Wiki https://valheim.fandom.com/wiki/Valheim_Wiki と Enshrouded紹介記事 https://www.gtxgaming.co.uk/building-new-worlds-exploring-enshroudeds-voxel-based-system/ 。Wiki直読は取得エラーのため検索結果と公式 https://www.valheimgame.com/faq/ で補完した。

Valheimの準備/探索/制作/地域攻略の循環、低ポリゴンと照明・材質を組み合わせる考え方、Enshroudedの記事の編集/建築/探索を接続する考え方を参考にする。独自の世界・モデル・アイコンを使い、既存作品のアセットや名称を流用しない。記事にあるエンジン実装の推測を技術上の事実として採用しない。

## 実装
- セーブ済みの所持品・設備・ボス状態から次の目標を導く。採集対象/祭壇までの距離と方向、タップで該当メニューへ。チュートリアル進行フラグを追加せず既存ワールドでも使える。
- 持ち物をアイコン付きスロット、制作/建築を素材の所持数と性能付きカードに変更。制作可否/作業台条件を表示。5地域の簡易マップ、食事の即時操作。
- 設置する部品の透過プレビュー、90度回転、素材不足/自分との重なり/距離の説明。共通の座標丸めと事前判定を使う。最終の支持・Authority判定は従来どおり。
- 近距離前方の敵への攻撃補助、攻撃長押し、スティック方向回避、命中粒子/音/被弾縁表示、敵攻撃の予兆。360度/真上/真下と連続放水を維持。
- カメラ距離と感度調整、近い標準カメラ。採集と放水が重なる旧CSSの優先順位バグを修正。
- 地形メッシュへ追従する草を1 draw call/最大2200株で表示。編集時に植生を作り直す。樹木は落葉樹/針葉樹、実を分かりやすく、建築は板材・梁・石積み・家具に分解。
- 近傍44mの太陽影1024px、約8Hz更新、設定で無効化可能。空の雲、空気感、影との明暗、波紋、衣服・髪・顔のディテール。命中と採集の粒子は120個の固定プール。描画資源は破棄。

## 限界
完成版Valheim/Enshroudedと同等の制作規模・画質を達成したものではない。草は近傍、影は近傍だけ。スマホ実機GPU性能はユーザーレビューで確認が必要。建築の緑は素材/位置の事前確認で、支持の完全な予測ではない。地域マップは模式図で全世界の測量地図ではない。ボス専用アニメーション、地形の追加編集種類、流体の物体押し退け等は残る。全仕様の完成と扱わない。

## 検証
型、関連単体、ビルドを一度実行。CIのAndroid相当操作・制作/保存・設置/回転・shaderエラーとスクリーンショットで確認。今回通信を変えていないためHost/Dedicatedの全接続検証は再実行しない。前回の採集ボタンが放水に覆われる失敗は、今回の操作テストを通すまで解消扱いにしない。
