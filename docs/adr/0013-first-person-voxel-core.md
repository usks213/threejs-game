# 0013: 一人称Voxelコアを独立試作する

2026-10-04。最新のユーザー指示はコアの作り直しとプロトタイプ検証。前の全草原要件より今回の横画面・一人称アクション・照準操作・細粒度Voxelを優先する。

mainを基点に専用featureブランチを作る。PR #3の草原版と保存データを上書きしない。旧ゲームの追加UIを持ち込まず、HP/スタミナ/照準/現在装備/回復/停止に絞る。スマホの戦闘ボタンは入力手段として残す。世界の対象操作は照準と到達距離・遮蔽が成立した場合のみ提示する。

一辺が既存1mの1/8となる0.125m水セルを採用する。「セル体積1/8」ではなく「一辺1/8」の解釈で、体積は1/512になる。水の領域は6×6×1.5mに限定し、27,648の占有/水量セルを扱う。大規模世界へ展開する性能はこの試作の合格に含めない。

固体は0.25mグリッドを正本としてVoxel DDA、体積コリジョン、表面メッシュを共通化する。敵/武器も小さいVoxelFieldから表面を生成。開いた扉は別の占有Voxelへ置き換える。水は固体グリッドをセル中心で照合し、重なった水量を領域内の空き容量へ排出する。全領域満杯の場合は未配分量を削除せず保持する。

ゲームのルールはThree.jsとDOMから分離する。固定60Hzの戦闘と移動、水10Hz、表示面更新5Hz。固体は変更した4mチャンクと隣接境界のみ再メッシュ化。高負荷時に画面解像度を下げるがHDR機能は保持する。実機FPSとブラウザのソフトウェアGPU値を区別する。

受入: 横画面停止/復帰、PCマウス/キーボード、スマホ複数指、遮蔽物越し操作拒否、扉のコリジョン変化、時間と向きを使う近接戦、破壊したVoxelと照準/コリジョンの一致、水の粒度/量保存/固体排除。CI・デプロイ・実機評価の未実施を成功扱いしない。
