# ADR 0013: 横画面のアクションと共有Voxelモデル

2026-10-04。最新のコア改善指示を優先する。mainへの昇格はプレイレビュー後。

## 表示と入力

ゲームの論理Viewportは常に横長とする。全画面・横向きボタンからブラウザのFullscreen/Orientation APIを試み、未対応・拒否時はCSSで横画面を維持する。縦持ちではゲーム全体を90度回転し、スティック・視点の差分も同じ座標に変換する。端末自体のOS回転を強制できたとは報告しない。Safe Areaを回転に合わせる。

PCはPointer Lockの相対マウス、左攻撃、右押下中ガード、WASD移動、Space跳躍、Ctrl/C回避、Shift押下中走行、E照準インタラクト、Tab持ち物、B建築、R強攻撃/建築回転、F放水、1–8クイックスロット、Escapeメニュー閉じ・Pointer Lock解除。建築中の右クリックは終了。タッチは同時ポインタを維持。ガードは押下中。

## 照準インタラクト

Three.jsに依存しない対象選択を使用。近くの対象への自動吸着を除去し、照準線上の資源・墓標・設備だけを選ぶ。建築・木は実際の占有Voxelを遮蔽物に使う。Authorityは対象ID、距離、地形遮蔽を再確認する。箱は指定した箱のパネルを開き、出し入れは箱ID付き。作業台・商人・扉・料理台・焚き火・寝床・祭壇もその場の対象から使う。互換性用の旧Domainアクションは残すが、ゲーム画面に万能な近傍操作一覧を置かない。

## Voxel

地形の共通サンプリング間隔を1mから0.5mへ変更。全Brickで同じ格子を使い、境界の不一致を作らない。遠景は既存の境界保持LOD。開始地点周囲のメッシュ完了時にプレイを始め、遠方は継続生成する。

木は0.25m、建築は0.125mの純粋な占有モデルを共有する。描画は内部面を除去した材質別メッシュ。未破壊の木はInstancedMesh、破壊された木だけ固有メッシュ。幹・建物に攻撃するとセルを削り、差分を保存する。建物の穴は人/敵の衝突と水の遮蔽に反映する。水用Colliderは隣接VoxelをSlabに結合する。アニメーションするキャラクター・動物・岩・丸太・小物の旧曲面プリミティブも占有セルから再構成する。UI/粒子/草の細い描画表現は描画用例外。

建物から回収できる資材総量は制作コストを超えない。削ったVoxelは材質ごとの回収片としてまとめる。素材量を毎セル1個として無制限増殖させない。破壊・解体・支持崩壊・修理の残量を共有する。木は伐倒/丸太分割の既存物理を維持する。

## 水と保存

Generator 3の水セルの辺を0.5mとし、体積を0.125m³（旧セルの1/8）にする。volumeは高さでなく実体積。水面の高さはvolume/セル面積。生成・保存の総数制限はない。2048セルを近傍シミュレーション予算、8192セルを近傍表示予算とする。遠方を削除しない。旧Generator 1/2は1mを維持。size未指定の旧1mセルは水面と総量を保って0.5mへ分割する。version 1/2を維持し、optional size / removed / drop / velocity / salvageを検証する。

## 戦闘・持ち物

近傍敵への自動照準を削除。近接は開始時にスタミナ消費、0.16秒/強撃0.32秒の振り始め、方向と間合い/遮蔽による命中、回復時間。回復最後の0.2秒に入力を1件バッファする。回避0.48秒のうち限定区間だけ無敵。向きは攻撃/ガード中に移動で上書きしない。

アイテムDropはID・個数・速度を持つ地面の物体。重力と水流を受け、明示的に拾うまで所有権を移さない。空き枠/荷重に応じた部分回収、近傍スタック結合、保存復元を行う。動物/敵/ボス/木材/採掘の素材は地面へ落とす。32枠の先頭8枠をクイックスロットにし、枠移動で割り当てる。

## 検証の範囲

関連単体テスト、型、ビルドとAndroidの新しい操作/描画チェック。PCのPointer Lock・右ボタン押下/解除を別の短いケースで確認。Workerのメッシュ配信変更のみではHost/Signaling接続試験を要求しない（接続プロトコル変更時は必須）。CIのSwiftShaderを実機FPSや端末OS回転の成功証拠にしない。

## 追補: コアの整合性（2026-10-04、PR #3の継続）

表示だけのVoxel化ではなく、同じ占有セルを照準・接触・破壊・水遮蔽に使う。開いた扉/門はヒンジの移動と回転を `buildingPose` で共有する。開扉時に当たり判定を消したり、閉じた位置を照準/破壊対象にしたりしない。プレイヤー/敵の接触と視線は、削った穴と元から空洞のある部品を尊重する。建築接続はカタログの概略寸法でなく実際のVoxel境界へ揃え、内部の重なりを拒否する。

インタラクトのAuthority検証を対象ID・到達距離・送信されたヒット点の対象範囲・地形/建築/木の遮蔽へ拡張する。遠隔の対象IDへ近い地面の座標を添える操作も拒否する。照準UIだけの制限に依存しない。

戦闘は至近距離でも前方の攻撃円錐を使い、飛び道具の近傍敵への自動吸着を除く。攻撃の回復中は回避/盾でキャンセルできず、攻撃/回避終了後に短いスタミナ回復待ちを置く。硬直中の盾の押下は保持し、硬直後に構える。離した入力は予約しない。ガード解除・メニュー・フォーカス喪失・画面回転で入力の押下状態を残さない。第三者視点カメラもVoxel壁/木に遮られる。

持ち物総量を正本にして32枠の表示を照合し、古い枠情報だけで満杯判定しない。分割や移動の配置を保持し、不正個数を拒否する。地面Dropは建物のVoxel床/壁へ接触し、削った穴を通る。拾えた個数だけをDropから引く。

これは接触と戦闘ルールの改善であり、人物/動物の全身破壊、精密な骨格衝突、実機FPS、全プリプロダクションの完成を示さない。PR #4のSDF/モーション試作は混ぜない。

## 追補: Terrain Workerと主スレッド予算

スマホ実機の重さ/ボタン重複報告を優先し、`docs/milestones/mobile-performance-pass.md` の比較と受入を追加した。生成はシミュレーションWorkerから専用Terrain Workerへ分離。World差分同期、epoch/version、遠方破棄、4メッシュの未消費クレジット、RAFの2チャンク/512KiB/soft 2ms適用予算を採用。メッシュの相対座標/境界/草配置を生成側で準備する。Workerローカル制御は `local-protocol.ts` に置き、セーブ/マルチプレイのwire形式は変えない。スマホUIは絶対配置の積み重ねを止め、論理Viewportに対する非重複Grid領域にする。
