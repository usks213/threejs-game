# ADR 0012: 草原キャンペーンと保存互換

2026-10-04。プリプロダクションの再定義により新規ゲームを草原の生存進行へ変更する。

- 地形Generator 3を追加。Generator 1/2の密度関数は変更せず、旧Voxel編集/水/岩を維持。
- 新規地形は小川、池、海岸を持つ。自然水も既存FluidGridへ入れ、掘削と放水を共通シミュレーションで扱う。
- AdventureSaveの任意`meadows`に3食、品質/耐久、装備、熟練、環境/進行を追加。旧セーブは旧キャンペーンのまま読める。
- 新規草原のIndexedDBは`threejs-survival-meadows`、従来は`threejs-survival-phase0`。既存DBを削除しない。`?campaign=legacy`で従来DBを選べる。手動書出/読込は維持。
- ワールド共有と個人状態を区別。設備の生産/燃料はホストが1回だけ更新する。
- 原作全要素の完全再現は未完了。要件表の未実装を残し、受入前に完成と宣言しない。
