# 0009 常時放水と水流の影響、タッチHUD

放水が照準ヒット・操作間隔・2048セル上限に阻まれていたため、水だけを地形編集の制限から分離する。専用放水ボタンと水ツールは長押し120msごとに放水。照準がない場合はプレイヤー前方へ出す。Authorityも近傍の放水点へ補正し、他アクションのクールダウン中も許可する。

セル間で実際に移動した体積と放水方向から水平流速を持たせる。浸水率に応じてプレイヤー/Guestを流し、岩/木材には抗力と浮力、敵には水流による移動を適用。ボスは重く流されにくい。現状はセル流体と球体接触による近似で、物体の体積に応じた水の押し退け、圧力による破壊、完全な流体ソルバーではない。

2048は生成/保存上限ではなく近傍の処理・描画予算。遠方の水は保存したまま処理を休止する。大量の連続放水では保存サイズとメモリは増える。vx/vzは既存version2の任意項目として追加し、旧データは0を補う。長押しの各通知では全体保存を発行せず、既存の定期・手動・非表示時保存を利用する。

ゲームHUDはHP/体力/魔力バー、丸いアクションボタン、青い放水ボタン、下部ツールを常設。保存・デバッグ情報はメニューへ収納。全操作48px以上で縦横対応、長押しはpointercancel/blur/回転で解除する。

検証：型、単体71件、ビルドがローカル成功。水の量保存・実流量による流速・プレイヤー/岩/敵への影響・Guestの連続放水・旧保存互換を確認。Android相当の二指長押しと保存メニューはCIで確認し、デプロイ/CI結果を正本とする。
