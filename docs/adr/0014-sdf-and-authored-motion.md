# 0014: Voxelを距離データとして扱い、モーションを戦闘の正本にする

2026-10-04。最新指示は「Minecraft式Voxel表示ではなく、Voxelデータ→SDF→リアルタイムメッシュ」「Dark and Darkerを意識」「モーションがとにかく大事」。0013の占有セル/表面の立方体面/DDA方針を置き換える。

疎な距離VoxelにCSG形状をラスタライズし、内外の符号と材質を保存する。Marching Tetrahedraでゼロ等値面を抽出。6四面体の内挿を照準/当たり判定にも用いる。球状差分、扉データ置換に対して変更4mチャンクと共有境界を再生成する。生成頂点のSDF誤差と法線、編集後の遮蔽を検証する。スマホ性能のためCPUで狭い範囲のみ生成し、生成時間をF3で測れる。GPUメッシュ化や大規模ワールドを完成扱いしない。

人体/装備も距離Voxelから表面生成した関節パーツ。腕二骨IK、肩/腰/重心/足を共通の手付け攻撃曲線で動かす。斜め斬り・返し・強撃は全行程を連続補間し、一定の刃長を保つ。敵も同曲線を遅めに動かし、予告から振り抜きまで読めるようにする。

攻撃の正本は武器のモーション。命中瞬間を固定タイマーや照準コーンで即決しない。曲線の刃を3.5cm以下の間隔で掃引し、頭/胴カプセルと接触したときのみダメージ、SDF壁に接触すると壁以降を遮断する。ガードは正面・盾の上がり・盾位置の近似被覆を必要とする。ヒットストップと怯みの姿勢遷移を加える。反転した視点で万能な攻撃ができないよう振りの最中の視点/移動を減速する。

1/4速度は操作感の代替試験ではなくモーションの確認用。通常速度の手触りと実機FPSは本人による実プレイの評価が必要。mainは本人のOK前に変更しない。
