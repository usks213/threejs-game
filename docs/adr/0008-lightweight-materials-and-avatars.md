# ADR 0008 — 小さなAtlasとキャラクター表示

2026-10-04。単色の地面と装備が見えないキャラクターを改善する。

地形は64px四枚を64×256の共有DataTextureにまとめる。RGBAの生データは64KiB。ワールド座標のTriplanarサンプリングでBrick境界をまたいでもUVが連続する。近景の模様は小さく控えめにし、地域のVertex Colorを維持する。高価なpost processingや別の画面バッファは使わない。

プレイヤー・資源・敵・静止した岩の接地影を一つのInstancedMeshで描く。64×64の半透明マスクを共有し、1 draw call追加する。これは太陽からの投影影やSSAOではない。高さに応じる薄い霧も地形シェーダー内の近似であり、光芒を描く方式ではない。

アバターは共有Geometry/Materialを使う簡易リグにする。歩行・空中・攻撃・ガード・回避の姿勢と、剣/大剣/斧/槍/弓/杖/魔導書/盾を描く。武器ごとの本格アニメーションの完成ではない。協力プレイのSnapshotに表示用の装備/姿勢だけを載せ、Inventory全体は他プレイヤーへ渡さない。離脱時のGPU資源は共有オーナーが終了時に破棄する。

水は既存の変位に合わせて法線を動かし、斜めから見たときの反射色を近似する。別シーンの反射/屈折render targetは使わない。

検証は既存の起動/移動/水/保存E2Eに加え、装備を切り替えて水を表示するE2EでWebGL/Shader console errorも検出する。CIスクリーンショットを保存する。これをAndroid実機GPU性能の実測とは扱わない。
