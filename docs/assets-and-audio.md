# Original assets and runtime notices

The campaign uses original procedural assets. No Enshrouded or Nintendo model, texture, map, recorded sound, character name, or written lore is distributed. Reference requirements describe mechanics, not licensed game content.

| Asset | Source | Scope |
|---|---|---|
| Terrain, buildings, plants and material colours | core/world.ts, campaign-world.ts, regional-world.ts, expedition-west.ts, rendering/meshes.ts | Original authored SDF operations and vertex material parameters |
| Enemy/player rigs, fishing equipment, hearth flame and effects | src/prototype/rendering | Original code-generated geometry, colours and animation |
| Combat effects, ambience and harmonic bed | src/prototype/audio.ts | Original procedural synthesis; no recordings or copied melody |
| Rendering engine, Sky and post-processing helpers | three 0.180.0 | MIT; full notice is included at /THIRD_PARTY_NOTICES.txt |
| Fonts and Unicode symbols | Device/system fonts | No font binary is bundled |

The public model, texture, sound and music directories contain no downloaded game assets. Visual quality and listening quality are separate acceptance items; original provenance does not imply parity with the reference game.
