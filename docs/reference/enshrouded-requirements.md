## 3 推奨実装順と依存関係

1. **P0 基盤**: データ定義、ゲーム状態、入力、衝突、セーブ、安全な再開。
2. **P1 一周遊べる進行**: 採集 → 制作 → 準備 → 危険地域 → 戦闘/報酬 → 帰還 → 拠点/装備/地域解放。
3. **P2 遊びの厚み**: 分岐する戦闘ビルド、NPC、農業、洞窟/塔/集落、複数の地域・ボス。
4. **P3 表現と操作**: UI、音、人物アニメーション、地形・空・水・霧・光。文字ラベルだけで機能が存在するように見せない。
5. **P4 追加システム**: 完全な水シミュレーション、ネットワーク協力、共有機能。保存・権限・同期の設計が先。
6. **全段階でQA**: 自動テストだけでなく実際の新規開始からの操作。最後に公開プレビューを再確認。

依存グラフ: アイテムID → インベントリ → レシピ → NPC/設備 → 装備/拠点強化 → 危険度ゲート → 地域 → ボス → 報酬 → 永続化回帰。移動/衝突 → グライド/フック → 立体POI → 敵AI/カメラ。ワールド編集 → チャンク保存 → 水/マルチプレイ。

「仮」の最低実装と、原作の範囲との差は各IDの実装記録で分ける。全行は初期状態を未検証とし、コード確認だけでチェックしない。

## 4 基盤と移動の受入チェック

以下は独自ゲームへの実装・試験要件。括弧内は依存先。各行末は合格条件です。

- [ ] F01 ゲーム開始と再開: 新規/続き/設定を区別。新規世界で開始地点が地形内や敵群内にならない。
- [ ] F02 安全な入力状態: 移動中に設定・インベントリを開いて閉じてもキー押しっぱなしが残らない。フォーカス喪失後も同様。
- [ ] F03 地形衝突: 平地・坂・段差・壁・屋根を移動し、抜け落ちや天井貫通がない。端で停止しても浮遊しない。
- [ ] F04 歩行/走行: 方向入力とカメラ方向が一致。走行はスタミナと連動し、空でも通常歩行で復帰できる。
- [ ] F05 ジャンプ/着地: 空中連打による無限ジャンプを防ぐ。着地、落下ダメージ、段差の判定を分ける。
- [ ] F06 カメラ: 壁際でも自分と目標を見失わない。ズーム・感度設定を保存し、初回視点が地面や背中内部に入らない。
- [ ] F07 グライダー (F05): 高所から起動→方向制御→消費→解除→着地が動く。資源切れを事前に表示。
- [ ] F08 フック (F03): 有効アンカーだけ提示し、射程外・遮蔽物越しは拒否。移動後に壁へ埋まらない。
- [ ] F09 垂直移動: 梯子/登攀可能壁の入口・出口が成立。普通の壁を無条件に登れない。
- [ ] F10 水泳/潜水: 水面/水中/陸上を切替。酸素ゼロの結果が明確で、浮上後に回復。水中攻撃の採否を明示。
- [ ] F11 死亡/復活: 原因を表示し、安全な帰還点へ戻る。資源喪失・回収ルールを選定し、二重ドロップを防ぐ。
- [ ] F12 救済: 地形編集で閉じ込められても、定義済みの安全帰還で再開できる。報酬・体力回復の無限悪用に注意。
- [ ] F13 時間刻み: 30/60/120fps相当のシミュレーションで移動距離・ダメージ頻度・採集量が実質同じ。
- [ ] F14 ロード状態: 読み込み/失敗/再試行を区別。真っ黒な画面や無限待機にしない。

## 5 探索と生存の受入チェック

- [ ] E01 オープンワールド: 拠点から少なくとも複数方向へ探索可能。壁だけの一本道をオープンワールドと呼ばない。
- [ ] E02 霧危険地域: 境界を視認でき、入域で残り時間、退域で回復。画面の色変更だけで終わらせない。
- [ ] E03 致死危険度: 現在の耐性では進めない地域を明示。帰還可能な警告時間を設け、強化後に通過できる。
- [ ] E04 霧内の報酬: 安全地帯で取れない素材/敵/遺跡があり、危険を冒す理由がある。
- [ ] E05 地図: 発見済み地域、現在地、方角、拠点、目的地が一致。遠近移動後もアイコンがずれない。
- [ ] E06 地図ピン: 配置/移動/削除/保存ができる。クエスト追跡と手動ピンを区別。
- [ ] E07 高所ランドマーク: 塔や山を見て方角を推測できる。到達後に周囲の見通し/移動上の利点がある。
- [ ] E08 移動網: 発見/解放した地点だけ高速移動可能。未解放地点をクリックして進行ゲートを飛ばせない。
- [ ] E09 昼夜: 光だけでなく、敵・資源・入口の少なくとも一つが変わる。待機/睡眠の時間更新も検証。
- [ ] E10 天候: 晴れ/雨等で画と音が変化。屋内で雨が降らず、設定を下げても危険情報は見える。
- [ ] E11 寒冷: 寒い地域への接近表示、保温装備/食事/火の軽減、退域回復が連動。
- [ ] E12 休息: 屋根・火・家具などの条件と効果がUIで分かる。家具の重複大量配置による無制限増加を防ぐ。
- [ ] E13 食事: 食料の効果・持続・枠/重複ルールを明記。空腹を採用するならゲーム独自仕様/選択モードとする。
- [ ] E14 状態異常: 毒/呪い等はアイコン・残時間・治療方法がある。解除後に残留ダメージが走らない。
- [ ] E15 宝箱: 開封状態を保存。リロードだけで再抽選できない。再出現させるなら条件を定義。
- [ ] E16 発見報酬: 同一地点再訪で無限経験値を得ない。隠し部屋・洞窟の発見に明確な結果がある。

## 6 採集と制作の受入チェック

- [ ] C01 アイテム定義: 全アイテムに一意ID、名称、分類、アイコン、スタック上限、説明、入手経路を定義。
- [ ] C02 採集: 木・岩・植物で道具/所要時間/成果が変わる。遠すぎる対象、壁越し、枯渇済み対象を採れない。
- [ ] C03 採掘: 地形の見た目と衝突が同時に変わる。掘った穴が再読み込み後も規定範囲で残る。
- [ ] C04 資源段階: 初期素材で初期道具を作れる。上位素材取得に上位道具が必要な場合、依存が循環しない。
- [ ] C05 インベントリ: 満杯、スタック分割、結合、並び替え、移動、落とす、拾うを検証。数量保存則が成立。
- [ ] C06 レシピ表示: 必要数/所持数/設備/解放条件/不足理由を表示。未解放と素材不足を区別。
- [ ] C07 制作トランザクション: 成功時だけ正確に消費。連打・閉じる・容量不足でも複製/消失しない。
- [ ] C08 複数個制作: 1/最大/指定数で計算一致。最大値0や大量数で負数にならない。
- [ ] C09 設備制作: 作業台・炉等に対応レシピと利用範囲を設定。存在しない設備を参照できない。
- [ ] C10 生産待ち: 入力→加工時間→出力の状態が見える。離れる/保存/再開の扱いが一貫。
- [ ] C11 収納: 個人持物と拠点チェストを区別。関連収納から制作するならアクセス範囲と優先順を表示。
- [ ] C12 一括収納: 既存スタックに統合し、対象外収納へ入れない。満杯時も数量が保存される。
- [ ] C13 修理/耐久: 耐久0、修理、交換の結果が明確。破損を知らせず攻撃不能にしない。
- [ ] C14 解体: 分解確認と成果プレビュー。装備中/クエスト必須品の誤解体を防ぐ。
- [ ] C15 入手ヒント: 不足素材から「森林で伐採」等の具体的行動へ辿れる。攻略文書を開かなくても進める。
- [ ] C16 収集図鑑: 発見済み/未発見、地域、用途を表示。図鑑登録が素材を消費しない。

## 7 戦闘と成長の受入チェック

- [ ] B01 基本攻撃: 射程・向き・遮蔽・クールダウンを検証。遠くの敵や背後の敵へ無条件命中しない。
- [ ] B02 重攻撃: 長押し→溜め/予備動作→強打→硬直が通常攻撃と違う。メニュークリックで暴発しない。
- [ ] B03 防御: 正面/背面、スタミナ、ガード崩しを区別。永久ガードで全攻撃無効にならない。
- [ ] B04 パリィ: 成功受付窓と失敗が分かる。成功音・姿勢崩し・反撃機会がある。
- [ ] B05 回避: 移動方向・消費・無敵時間・硬直を定義。回避連打で無限無敵にならない。
- [ ] B06 弓: 照準・弾数・射程・発射体・着弾を連動。空弾、遮蔽、射線外で正しく不発。
- [ ] B07 魔法: マナ/詠唱/属性/範囲を定義。初期から魔法ルートに入れ、弾切れ後に制作で復帰可能。
- [ ] B08 武器差: 片手+盾、両手、短剣、弓、魔法の採用分は間合いとリスクが違う。色違いだけにしない。
- [ ] B09 特殊技: 通常戦闘でメーターが蓄積し、満タン時にのみ発動。使用で消費し、対応武器の解放条件を持つ。
- [ ] B10 属性: 耐性/弱点/状態異常が実際のダメージへ反映。色だけでなく数値や記号でも伝える。
- [ ] B11 敵AI: 待機→巡回→警戒→捜索→追跡→攻撃→帰還の採用状態を検証。視認/聴覚を混同しない。
- [ ] B12 敵移動: 木・壁・崖を避ける。到達不能なプレイヤー相手に停止や壁抜けを無限継続しない。
- [ ] B13 敵の予備動作: 強攻撃・遠距離・範囲攻撃を発動前に読み取れる。命中前にダメージが出ない。
- [ ] B14 複数敵: 敵同士の重なりを抑制し、囲まれても視点が破綻しない。最大同時数を負荷試験。
- [ ] B15 ボス段階: 体力条件などで行動が変化。死亡、再挑戦、エリア離脱で状態を正しく初期化。
- [ ] B16 ボス報酬: 必須進行素材を確実に受領可能。満杯時に永久消滅させず、重複報酬を防止。
- [ ] B17 経験値: 採集/探索/戦闘/クエストの採用経路が実際に加算。レベルアップ条件と上限をテスト。
- [ ] B18 スキル: 前提・コスト・効果・上限が一致。取得/強化/再配分でポイント総量が保存される。
- [ ] B19 装備成長: レベル・品質・強化・追加効果を区別。装備更新で実際の攻防が変わる。
- [ ] B20 ジェム: 対応スロットのみ装着。交換/取外し/強化のアイテム消費ルールが一貫。
- [ ] B21 ビルド成立: 近接/遠距離/魔法の採用ルートで、同じ主要ボスまで新規開始から到達できる。
- [ ] B22 戦闘明瞭性: 自分HP、敵HP、対象、ダメージ、回復、危険の情報が重ならず読める。

## 8 拠点と住人の受入チェック

- [ ] H01 拠点核: 設置条件/領域/復活地点を明示。建築範囲拡大と危険耐性強化を別効果として説明。
- [ ] H02 配置プレビュー: 有効/無効、必要素材、向き、位置を確認できる。無効配置では消費しない。
- [ ] H03 建築形状: 床・壁・屋根・階段・扉・窓の採用部品で、出入り可能な家を完成できる。
- [ ] H04 地形編集: 追加/削除/整地の見た目と当たり判定が一致。プレイヤー内部への配置を防ぐ。
- [ ] H05 回転/スナップ: 壁・床の継ぎ目に隙間ができない。自由配置とグリッドの切替が分かる。
- [ ] H06 削除/返却: 削除対象を明示し、資源返却率を一定にする。収納削除時に中身を失わない。
- [ ] H07 Undo: 採用する場合、直前操作の地形/資源を両方戻す。二重返却を防止。
- [ ] H08 家具: ベッド・火・光・収納・設備に実機能。座れる家具を飾りと混同しない。

## 14 完了判定とQA記録

各IDについて次の状態を記録します。

- **完了**: 実装箇所と具体的な実行証拠がある。
- **簡易実装**: 採用した部分と省略した部分を列記。原作相当とは数えない。
