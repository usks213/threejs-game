# H11: 鍛冶師ナギの暮らし（第一段階）

## 実装した範囲

- 墓所での救出条件、支給品、経験値は既存の `CampaignSystem` を唯一の正本として維持。救出時だけ従来と同じ拠点への帰還が起き、その後は実際の足場上を歩く。
- 8〜12時・14〜18時は炉辺で道具の手入れ、6〜8時・12〜14時・18〜22時は交流場所へ移動、22〜6時は休息。交流中は挨拶の身振りと現在位置での会話ができる。自動生産、追加の資源配布、ほかの住人との会話イベントは含まない。
- 布張りの寝台が実際の地形レイヤーに存在し、上に屋根がある場合、そこへ歩いて登り、寝台上に座った睡眠姿勢になる。家具の台帳だけでは就寝しない。寝台・屋根がない場合は炉辺で休み、必要条件を表示する。雨天は既存の屋根の下へ移動する。
- `NpcLife` は 30 Hz の固定刻み。キャンプ内の 12×11 の経路候補を実際の SDF、頭上の空き、段差、複数の足場点で検査する。薄い壁をまたがず、閉じた囲いから瞬間移動せず、通れなければ待つ。人が近づくと脇に避け、身体や設備を押し動かさない。
- 床が消えると重力で落下。奈落落下、または読み込み時の既存建築との埋まりだけは、キャンプ内の支持と空間を確認した場所で救済する。安全地点がない場合は非表示の待機状態を保存し、建築や所持品は変更しない。
- 立位、歩行、道具の手入れ、交流、休息の独自 SDF 姿勢をキャッシュし、描画と照準は同じ身体を使う。毎フレームの世界レイヤー移動や地形再メッシュは行わない。身体は保護対象で、採掘・攻撃・矢から素材や報酬を生まない。
- プレイヤー、敵、山羊、建築と扉に身体を反映。ナギに重なる家具は支払い前に拒否する。炉での既存制作はナギの時刻・位置を条件にしない。
- 新しい optional `npcLife` 保存フィールドとホスト発行の表示フレームで状態を保存・同期する。旧保存は救出済みフラグを確認し、古い固定身体だけを一度除去して復元する。凍結済み `campaign-v2/v3/v4` の生成基準、既存報酬、地域台帳は変えない。オフライン時間の進行はない。

## 検証

`tests/unit/npc-life.test.ts` は時刻境界、実歩行、30/60/120 Hz、壁の迂回、囲い、穴、他の身体、寝台と屋根、雨宿り、会話距離と遮蔽、読み込み救済、奈落救済、保存の独立性・拒否を確認する。

`tests/unit/npc-life-runtime.test.ts` は初回救出の有限支給、元の場所からの照準消失、現在位置の会話、反復会話による支給なし、旧固定身体を含む保存の復元、無効状態の原子的拒否、家具代金保護、時刻に依存しない制作、実キャンプの炉・寝台・交流位置への経路、保護身体、協力表示、GPUリソースの再利用と破棄を確認する。

既存の通常 Core プレイヤーによる第一章、全地域、西方職人、10分継続の回帰を実行する。第一章の通常救出からの保存も身体の連続性を確認する。PC/Android Playwright の通常第一章ケースに、救出後の現在位置での会話と報酬不変、画像保存を追加した。

ローカル Chromium は既知の socket EPERM 制約により起動しないため、ブラウザ実行は未検証。E2E 定義のコンパイル・一覧確認は、実行成功の代わりにはしない。公開ブラウザでの日夜全行動、実機性能、睡眠姿勢の見た目の受入は残る。

## 残る範囲

H11 全体は部分実装。西方の木工師マキ・錬金師セナは従来の固定身体を維持している。両者の救出前/帰還先の正確な身体は西方セーブの地形整合性証明に含まれ、その検証を弱めて動かしてはいない。追加する場合は、独立した動的身体の保存状態と静的レイヤー抑制の対応を厳密に検証する明示的な移行が必要。

自由な寝床割り当て、複数住人の交流イベント、すべての任意建築を理解する汎用ナビゲーション、地形変更による安全地点が全くない場合の自動建築修理、横たわる睡眠アニメーションは実装していない。

統合レビューで、プレイヤーがナギへ垂直に落下した後、重なりから互いに離れられなくなるケースを修正しました。すでに接触している場合だけ、相手との距離が単調に増える水平移動を許可します。新しい身体への侵入、中心を突き抜ける移動、地形への侵入は許可しません。配置・扉には従来の身体範囲を保ちます。落下後の徒歩脱出、重なった保存からの復元、新規接触の拒否を含む23件の重点試験が通過しています。
