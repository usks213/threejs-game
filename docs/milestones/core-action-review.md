## 現在の制約

- 全身の破壊/骨格ごとの精密衝突は未実装。動物・人物はVoxel描画だが、接触判定はアクション用の簡略形状。
- 水は保存されるセルの近傍予算で進む。遠方の水を全世界同時に精密計算する仕組みではない。
- OSの向き固定がブラウザから許可されない端末ではCSS横画面を使用。
- 草/粒子は細い描画表現。地形の表面はSDFから滑らかに抽出する。
- 建築の支持・修理・解体は実装済み。部品の詳細な装飾と建築カメラの快適さは引き続きプレイ調整対象。
- 実機Android/iPhoneのFPS・操作感は本人のプレイで確認。CI値から品質完成を判断しない。
