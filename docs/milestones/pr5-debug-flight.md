# PR #5: スタミナ不要のデバッグ飛行

2026-10-06。ひとりプレイの冒険ワールド用の一時的な移動モード。

- 設定 → デバッグ →「デバッグ飛行 ON」で開始する。持ち物に翼がなくても使用でき、通常の滑空とスタミナ消費は変更しない。
- WASD／左スティックで水平移動。Spaceで上昇、Vで下降（既存のキーバインド変更に追従）。タッチでは右下の「上昇」「下降」を押し続ける。放すとその高さで停止する。
- 飛行中は翼を表示し、常設の右下操作に「飛行終了・安全な足場へ」を表示する。設定内のOFFでも終了できる。終了時は直下の安全な足場、または安全な復帰位置へ移動し、落下速度を残さない。
- メニュー、フォーカス喪失、画面回転、タッチキャンセルで上昇／下降入力を解除。飛行モード自体は維持する。死亡、出発点への復帰、リセット、再読込で解除する。
- 地形・木・建物・浮遊部品との接触と世界境界を維持する。無敵モードではない。
- 飛行中の保存は、再検証した離陸位置を使う。水や編集で離陸位置が危険になった場合は現在位置の下または出発地点周囲の安全な足場へ保存する。飛行フラグや空中座標を保存しない。安全な保存先がない場合は保存を見送り、操作を継続できる通知にする。
- 協力プレイでは使用不可と表示し、SessionAuthorityでも共有ルームのホスト／ゲスト両方の飛行操作と上昇／下降の偽造入力を拒否する。通常の滑空は協力プレイでも従来どおり。

## 検証

- 単体: 自由移動・静止・スタミナ・壁と天井・境界・不正入力・安全な終了と保存・水没／編集後の復帰先・死亡／リセット・乗り物との排他・共有ルーム権限。
- 入力: 二指操作、競合する上昇／下降、pointercancel、capture喪失、キーリピート、キー割当、メニュー／blur／回転／非表示／abortの解除。
- CI用ブラウザ: `voxel adventure debug flight`。PCとAndroid相当で移動＋上昇、下降、静止、メニューキャンセル、書出、安全な終了、再読込を確認する。ローカル実行可否・CI結果は実際の実行結果を参照し、実機の操作感／FPS検証とは区別する。
