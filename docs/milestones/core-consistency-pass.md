# PR #3 コア整合性パス

## 今回の目的

照準で採集 → 持ち物を整理 → 建築 → 壁/木を削る → 素材を拾う → 敵の攻撃を読み、盾/回避/攻撃を使う、という既存の遊びを破綻なくつなぐ。

## 重点レビュー

1. 敵を背中側に置いて近接攻撃。背後に自動で命中しないこと。攻撃直後は盾/回避で硬直を消せず、回復後に次の動作へ移れること。
2. 木や壁の向こうの素材は拾えず、穴を削る/扉を開くと通せること。開いた扉の見えている板を狙って閉じる/削ること。
3. 32枠で素材を分け、空き枠へ動かし、個数指定で落とし、満杯近くで部分回収。合計数と配置が維持されること。
4. 床に素材を落とす。床上で止まり、床を削ると落下すること。隣り合う床/壁は面で接続し、重なって設置されないこと。
5. PCで右ボタンを押したまま持ち物を開く/ウィンドウを切り替える。ガードが解除されること。スマホの回転/タッチキャンセル後に操作が残らないこと。

## 維持する仕様と制約

- 地形0.5m、木0.25m、建築0.125m、水0.5m。水の「1/8」は旧1mセルに対する体積で、辺の長さは1/2。
- 論理Viewportは常時横長。OSの回転固定はブラウザが許可する範囲のみ。未対応端末は回転したCSS表示で横画面を維持する。
- HDR/PBR描画、水量保存、旧セーブ互換、素材回収の上限を維持。
- 動物/人物の全身破壊、精密な部位衝突、実機Android/iPhoneのFPSと手触りは未完了/未確認。
- 元タスクが停止した時の未push差分にはアクセスできず、保存済みPR #3 HEAD `8ff0447` を基準に変更。PR #4とは分離。
