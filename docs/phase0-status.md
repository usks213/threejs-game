# 開発状況と遊び方

最新の全37章の進捗は[仕様実装状況](specs/implementation-status.md)へ集約しています。以前の地形だけのPhase 0から、採集・戦闘・クラフト・建築・地域ボス・協力プレイを実装した段階へ進みました。**全仕様の完成には至っていません。** 小さな公開ごとのレビューは依頼せず、残項目を実装します。

## 操作

左スティックで移動。画面ドラッグで水平360°・真上/真下まで視点変更。左指を離さず右指でジャンプできます。「視点を戻す」で復帰します。

採集ボタンは近くの木・石・木の実・鉱石を採ります。冒険メニューで装備や食事を作り、建築物を選び、地面に照準を合わせて設置します。攻撃・強撃・ガード・回避・魔法を使い、各地域の祭壇で素材を供えてボスを召喚。撃破すると次の地域の技術が解放されます。

掘る/盛る/水/岩は地形ツールです。岩を押す・飛び乗る・足元を掘る、水を穴に流す・出口を掘る、木材を浮かべる操作が可能です。寝床と焚き火で休息、箱で素材の保管、転移門を二つ作ると移動できます。

協力メニューのHost Gameで招待リンクを共有し、友達がJoin Gameで参加します。ホストが退出すると終了します。ホストのワールドが正本で、ゲストの個人ワールドは上書きしません。

## セーブ

自動保存は5秒ごとと編集後。端末とURLのオリジンごとに別の保存です。別URL/端末に移る前にJSONを書き出してください。読込上限は16MiB。旧generatorの地形は維持し、新規ワールドに新しい地域地形を使用します。ブラウザのサイトデータを消すと保存と専用サーバー参加者IDも消えます。

## 確認済みの制約

- 地形は1m格子の近似。細い形状や岸には粗さがあります。局所的な崩落破片は球形の衝突近似です。
- 岩の個数制限はありませんが、端末メモリが無限という意味ではありません。水2048セル、編集100,000回の予算があります。
- 水は有限セルの容量移送です。海洋規模・複雑なダム・大きな積み上げは受入確認が残っています。
- 水流/浮力/凍結、昼夜と天候は実装済み。地面の材質・接地影・装備と簡易モーションも追加。太陽の投影影/SSAO/光芒や専用モーションなど美術の仕上げは未完成です。
- 4実ブラウザHostと8実接続Dedicatedを検証。異なる外部ネットワーク・実機FPS・長時間の協力プレイは未確認です。
- Node専用サーバーの常設運用先は契約していません。通常の友達プレイにはHost Gameを使えます。
