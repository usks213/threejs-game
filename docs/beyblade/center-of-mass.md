# 部品の質量分布・3D重心・完全な慣性テンソル

**以下は共有された近似形状と未校正の質量・密度モデルからの計算です。メーカーの測定重心・測定密度ではありません。** 公式評価だけから実物の3D重心は一意に決まりません。公式の部品形状説明と評価を推定モデルの入力にし、計算値と出典の事実を分けます。

## 「重心高さだけ」からの変更

前版は縦方向の質量加重重心と、軸方向／横方向の慣性値まででした。現在のモデルは各部品の体積・質量分布を積分し、X/Y/Zの重心と6独立成分の対称慣性テンソルを計算します。重心移動と慣性変化は別です。例えば対称な外周重視リングは横重心が中心でも、回転を変えにくい慣性を持ちます。

- ブレード: 描画と共有の金属リム、樹脂コア、ハブを別の質量領域として積分。装飾の微小質量は未測定として近似から除外。
- ラチェット: 同じ突出輪郭と高さの均質な立体を積分。内部空洞・材質分布は未知で、実物の密度を断定しません。
- ビット: ギア・先端・ディスクの外接回転体を質量領域として近似。歯、球端、ディスク穴の詳細質量は近似であり、実接触形状との区別を明記。
- 公式評価による推定部品質量と、出典／評価に拘束された正のリム・コア密度比を維持。密度を各部の推定質量へ正規化した後に重心と慣性を導出し、別の都合のよいテンソルを後付けしません。密度比・実効密度も推定として詳細欄に表示。

閉じた三角形表面を符号付き四面体へ分け、体積・一次モーメント・二次モーメントを積分します。輪郭頂点へ等しい質量を置く方法ではありません。N回対称形状にはNの倍数の積分分割を使い、分割数による架空の偏心を防ぎます。2回対称は横重心が0でも、X/Z慣性が等しいとは限りません。

## 座標と合成

共通の基準はビット軸先の位置です。各部品の質量を mᵢ、基準座標での重心を cᵢ、部品自身の重心まわりのテンソルを Iᵢ とすると、

- M = Σmᵢ
- C = Σ(mᵢcᵢ) / M
- dᵢ = cᵢ − C
- I = Σ[Iᵢ + mᵢ((dᵢ·dᵢ)E − dᵢdᵢᵀ)]

テンソルの非対角要素は負の慣性乗積を含みます。取り付け向きは明記した基準方向で固定し、名前のハッシュや未根拠の取り付け角を追加しません。

物理状態の位置は世界座標のCOM、Quaternionは共通の部品軸から世界座標への姿勢です。床・刃・ラチェット・レール接触、発射時の先端配置、描画はすべて同じ `geometryToCOM` により **基準形状点 − C** を使います。内周リムを縮小する際も、COM移動後の座標を縮めて形を歪めず、基準座標で形状を作ってからCを引きます。

## 回転と解放

世界角運動量 L から ω = R I⁻¹ Rᵀ L を計算します。非対角項があるときやX/Z慣性が異なるとき、旧い対称コマの厳密解は使いません。一般テンソルのLie midpoint積分を使い、独立した高精度積分との刻み幅収束を検証します。回転エネルギーは½L·ω。先端の支持力とCOMからの腕による実トルクが傾き・歳差へ作用します。ロック解除トルクはCOMではなく実際の軸に対する腕で評価します。

バースト時も同じ部品質量・重心・テンソルを使います。部品初速は vᵢ = v + ω×R(cᵢ−C)、部品角運動量は回転したIᵢから計算し、質量・並進運動量・全角運動量・運動エネルギーと分離直前後の形状位置を保ちます。都合よく部品重心間隔を縮める旧いテンソル合わせは、新モデルでは使用しません。

## 画面と比較

拡大ビューの「重心とビット軸を表示」は実際のモデルCOMと軸線を同じ縮尺で表示します。位置差は拡大しません。見えるよう透視表示するマーカーは物理的な部品ではありません。高さ・横偏心・軸慣性を簡潔に表示し、全テンソル、主慣性、部品別寄与、領域密度は詳細欄で確認できます。

`node --import tsx scripts/compare-beyblade-com.ts` はブレードSword／ビットFを固定し、ラチェットだけを3-60／3-80／1-60／2-60／9-60へ交換します。[計算報告](com-comparisons.json)にはソースハッシュ、同じ発射仕事、単独傾斜床での歳差・自転・傾きの時間推移、共通入力衝突、通常軌道を記録します。ある時刻の傾きが小さいことだけを普遍的な安定性や強さの順位とは扱いません。

## 残る検証

質量・輪郭内部・密度・取り付け公差・摩擦・発射分布の実測校正は未実施です。物理不変量や異なるモデル挙動の検証は、実機と同じであることの証明ではありません。固定ステップ接触の位置補正による小さなエネルギー誤差も別途追跡し、隠れた速度倍率やエネルギー打切りで消しません。
