# パーツ別の推定物理モデル v4

**公式評価を物理モデルへ反映するよう改修したが、メーカー測定値・実物再現の保証ではない。** 評価表は無改変で保持し、以下の換算はすべて `ESTIMATED_UNMEASURED`。出典を目視確認したブレード系列の刃数・機構説明と、公開された部品評価を制約として使う。モデルの名前・IDをハッシュ化して架空の差を作ることはない。

再現コマンド:

```sh
node --import tsx scripts/compare-beyblade-models.ts
npx vitest run tests/unit/beyblade/model.test.ts tests/unit/beyblade/model-mechanics.test.ts tests/unit/beyblade/catalog.test.ts
```

出力: [`model-comparisons.json`](model-comparisons.json) と全行のコンパクトな [`model-audit.json`](model-audit.json)。式の実装は [`physical-estimates.ts`](../../src/beyblade/data/physical-estimates.ts)、個別の一次出典と観察結果は [`shape-facts.ts`](../../src/beyblade/data/shape-facts.ts) と [`expanded-shape-facts.ts`](../../src/beyblade/data/expanded-shape-facts.ts)。`modelMetadataFor(build)` がUIに公表値・未知入力・未再現機構・換算先・単位を渡す。

## 全カタログ監査

311行を走査。228行は発売・組立条件を満たす単体差し替えの比較対象で、モードを展開すると219種類の機械的ビルド署名になる。残る83行にはCX構成部品単体や発売／組立未確認が含まれる。CX単体の評価を創作せず、確認済み完成ブレードを通じてのみ扱う。

- プレイ可能ブレード138行中、104行（色違いを含む）は出典に基づく輪郭系列。
- **34行は「形状未再現・暫定モデル」**。評価による推定はあるが実物輪郭を再現していない。
- 署名は描画名・チーム色・材質色だけを除外し、質量・慣性・全接触形状・摩擦等を比較する。
- 8同等グループのうち、初期Hell Scythe／4-60／Tの行は各基準部品を差し替えても**同じ完成ビルド**になるため重複する。
- PhoenixWing黒色、DranDagger黒／白などは現データの評価・形状近似が一致するため同等。色だけで物性を変えない。
- HellsHammer等未対応の別色、および欠測のライノリーパーC、コラボ部品等の7行グループは**共有の暫定係数により区別不能**。実物が同じという意味ではない。JSONの `equivalentGroups` に全名前と理由を公開する。
- `auditModels()` は全行の理由とモード別プロフィールを返す。全件を異なる実物モデルにしたという主張はしない。

## 数値の換算規則

以下でA/D/Sは各部品の公式攻撃/防御/持久の **生値÷100**。合計を100へ正規化しないため金属塗装等の合計100超を潰さない。Xはダッシュ、Bは耐性、Hは高さコード。欠測はnullを保持し、UIの `missingInputs` に列挙したうえで公開した共通事前値（ブレード33/33/34、ラチェット11/13/6、ビット25/25/25/25・耐性50）を使う。

- ブレード接触深さ率 = clamp(出典形状の推定深さ + .10(A−.33) − .035(D−.33), .025, .30)。
- 外接半径[m] = .0265 × 出典形状半径係数 × clamp(.97+.04A+.04S,.96,1.08)。実際の輪郭は共有の非対称刃関数で描画と衝突に使う。
- ブレード質量[kg] = clamp((.026+.004(D−.35)+.002(A−.30)+.0015(S−.35))×出典形状の推定重量係数,.023,.035)。
- ラチェット質量 = .0053+.003(D−.13)+.0015(S−.06)。
- ビット質量 = .0022+.0015(D−.20)+.001(S−.20) + ディスクなら.0018 + MNなら.0007。
- ブレード外周配分係数 = clamp(出典形状係数+.15(S−.35)−.06(A−.30)+.025(D−.35),.48,.88)。
- 自転慣性 = bladeMass×outerRadius²×外周配分 + ratchetMass×ratchetRadius²×.55 + bitMass×(discRadiusまたは.006)²×.5。
- ラチェット半径 = clamp(.0153+.004(A−.11)−.002(D−.13)+形状追加,.014,.019)。5枚刃追加.001、8枚刃追加.0013。突出深さは0枚なら0、他はclamp(.035+.45A−.16D,.025,.15)。
- 高さ変位 = clamp((H−60)×.00008,−.0012,.0024)。**60=6mmという公式寸法とは扱わない。** 質量加重COMと各部の露出高さに反映。
- 先端半径 = 先端形状の基準半径×clamp(.85+.5A−.1S,.7,1.3)、O/LOは.7、FBは.65を乗じる（推定）。flat2.8mm、ball/taper1.5mm、needle.45mmが基準。
- 摩擦 = clamp((先端形状の基準摩擦+.14(A−.35)−.05(D−.20))×機構係数,.07,.6)。基準flat.24、ball.17、needle.14、taper.20。C/LC左回転1.18、MN.75、RA2.2は推定。
- 転がり損失 = .000004+.000028(1−S_bit)。自転減衰率[s⁻¹] = .010+.009(1−S_blade)+.006(1−S_bit)。各Sを0..1へ制限。材質反発係数は共通.48で、攻撃評価による反発ブーストを与えない。
- ギアピッチ半径 = .006×(歯数/12)×(Aなら1.18)×clamp(.975+.1X,.97,1.04)。R/LR/Wの10歯は一次情報、標準12歯と同じ歯ピッチという寸法仮定は推定。**歯数による架空の速度倍率はない。** 実半径を使った平均噛合拘束で自転エネルギーを移動へ変換する。
- GF/GB/GP/GNの先端まで延びたギアは接触高さ帯を6.5mm、他4.5mmと推定。形状は描画と共有する。
- detent剛性 = .006+.020B+.006D_ratchet、解除角 = .20+.08B+.05D_ratchet。解放障壁は½kθ²。実際にラチェットへ作用する解除方向の仕事でのみ解放し、勝敗ダイスや任意ダメージへ換算しない。
- シンプルジョイント4-55/M-85/9-65/7-55は**実効耐性30**、DSは優先して**20**。部品単体の公式値を書き換えない。出典: [CX02](https://beyblade.takaratomy.co.jp/beyblade-x/lineup/cx02.html)、[BX44](https://beyblade.takaratomy.co.jp/beyblade-x/lineup/bx44.html)、[UX16](https://beyblade.takaratomy.co.jp/beyblade-x/lineup/ux16.html)、[UX18](https://beyblade.takaratomy.co.jp/beyblade-x/lineup/ux18.html)、[BX50](https://beyblade.takaratomy.co.jp/beyblade-x/lineup/bx50.html)。
- 2-60の左右条件付き評価は選んだ回転に応じて表示するが、同じ実物の質量・慣性・形状は変化させない。不変評価だけを使い、左右攻撃差から固定された輪郭非対称性を推定する。

## 入力と比較方法

同じ「パワー」は固定RPMでなく**等しい推定ランチャー仕事**。回転仕事 E=.5(.55×.035×.024²)(170+440p)²、並進仕事 E=.5×.035((.45+1.45p)²+.12²)。下向きの初速も質量に応じて調整し、各質量・慣性で速度を解く。形状で変わる初期重力位置エネルギーはランチャー仕事に含めない。メーカーランチャーの実測校正ではない。

1. **単独減速**: 正立・床中央・初期並進速度0を明示した実験治具。3秒、同じ剛体/床接触solver。相手・レール・得点を無効化した専用関数を使い、Battle.resultを消して無理に継続しない。
2. **共通入力衝突**: 正立・共通高さ・300rad/s、同じ相手が1m/sで接近。無重力/無抵抗の空間で最初の実接触を記録。形状により接触時刻が変わる。運動量・損失から反動が生じ、評価点からキックを加えない。
3. **通常発射**: 同一入力で3秒の通常2体アリーナ。自機の軌道、レール接触・ダッシュ時刻を記録。カオス的な1試合の勝率から強さ順位を主張しない。

3-60/F固定でSword→Rodだけを変更すると、推定慣性1.16e−5→1.99e−5 kg·m²、等仕事発射の自転509.8→389.4 rad/s。3秒の単独残存運動エネルギーは64.7%→71.5%。Sword/3-60固定でF→Bだけを変更すると64.7%→87.9%。これは**モデル内部の機械的差**であり、実測の持久時間や実物ランキングではない。

## 未再現と校正の限界

自由回転FB/リング、弾性ダンパー、自動変形、point+flat接触遷移等は対応メタデータに未再現と明記。初期モード評価は反映するが勝手に自動遷移したと称さない。全質量・慣性・絶対寸法・摩擦・保持力は未計測。生産公差、摩耗、温度、実際のランチャー出力にも未校正。配色は公式代表画像からの近似で、ロゴ・商標図案・画像をコピーしない。


## v4 の出典に基づく拡張と分類訂正

73非CX調査系列を読み、明示した共有輪郭スタイルと接触区画数・推定寸法・配色へ落とし込めるものだけを実装した。**出典レコードが存在するだけでは形状未再現の表示を解除しない。** `bladeStyle=generic` は常に未再現となる全行テストがある。公式の刃数と画像から観察した主区画数はメタデータで区別する。

- GhostCircleは公式0枚刃。内部の計算上は1周期・突出深さ0の完全な円とし、架空の3枚刃を付けない。
- ClockMirageは公式60枚刃だが現接触サンプルで微細60歯を解像できない。円盤近似＋微細刃未再現の警告を残す。
- ScorpioSpearの6枚ディフェンス／3枚アタックは指定した初期輪郭のみ。マゼンタコート版も各モードを別の初期形状へ対応させ、ダッシュ連動の機械変形を実装したとは称さない。
- KnightMailの上下する3球、SamuraiSaberの開閉刃、ImpactDrake/MeteoDragoonのラバー材質、MummyCurseの自動変形、GloryValkyrieの可動ばね、LusterDragoonの横偏重心は未再現と明記する。
- IronMan/Luke/Optimus等は画像で4区画を観察した共通の粗い輪郭近似で、データ不足の場合に同一の機械署名になる。実物同等性の主張でも、個別の彫刻・ロゴの再現でもない。

一次画像のシリーズ表示に基づき、PteraSwing・TyrannoRoar・SharkGillは**BX部品**、HellsBraveJは**CX完成ブレード**へ訂正した。含まれたセットのUX/CX製品シリーズとは別属性に保持する。HellsBraveJは既存のHells lock chip、Brave main blade、J assist bladeへ結び、単体評価はnullのまま。すべてのID、公式評価値、製品リストを保持し、公開CSV/JSONとアプリ入力を一致させた。

再現: `node scripts/correct-beyblade-classifications.mjs`。出典は [`classification-corrections.json`](../../public/beyblade-data/classification-corrections.json)。
