**現在の到達点は、公式データ付きのプレイ可能な未校正プロトタイプです。実機と同じ物理挙動を達成したものではありません。**

- 新規画面 `/beyblade/`。既存 `/`、PR #3〜#6、本番Workerは変更対象外。
- モバイル・PC対応、オリジナル3D形状、シュートの強さ・方向・傾き、練習相手の選択。
- 出典を保持した部品評価台帳と製品一覧、CSV/JSONダウンロード、発売予定・未確認値の区別。**全製品・全パーツの網羅は未達**。詳細は[調査範囲](catalog.md)。
- BX/UX部品交換、検証済みCX組立プリセット、ラチェット一体型の整合性チェック。未確認CX自由組合せは未対応。
- 日本公式第12版の「2人・1ベイ・4ポイント先取」を採用。3on3・シュート反則の共通ロジックは単体テスト済みですが、3on3の画面・オンライン対戦は未対応。
- サーバー権威型の匿名マッチング、両者ready、同期得点、次ラウンド、キャンセル、再接続猶予、退出判定。

## シュート操作とリザルト

- 「ポインターで位置を選ぶ」から青い範囲をクリック・タップ、またはドラッグ。矢印キーで5 mmずつ調整し、Enterで確定できます。初期位置へ戻すボタンもあります。
- 選べる中心位置は半径12 cm以内・自分側Xが中心から4 cm以上。初期重なりを避けるプロトタイプの制約です。オンラインの2人目は右側になります。位置は実際の物理開始位置に使い、サーバーでも検証します。指定しない旧クライアントの初期状態は変わりません。
- 「話してシュート設定を入力」で、例「パワー80、角度マイナス10、傾き5」を音声または文字で入力。「内容を確認」→「設定に反映」で変更します。対応項目はパワー20〜100%、角度−50〜50°、傾き0〜30°の整数です。自由なゲームルール変更や音声での自動シュートには対応していません。
- マイクは音声入力ボタンを押したときだけ起動。認識はブラウザーのサービスを使用し、音声が外部サービスへ送信される場合があります。認識不可・非対応時は文字入力を利用できます。認識の実機精度・Safari実機は未検証です。
- シュート開始時に設定を固定。カウントダウン中や対戦中、オンライン準備送信後は編集できません。
- 決着直後にフィニッシュ名、勝敗、獲得点、合計スコアを表示。試合終了とラウンド終了、引き分け、退出による決着を区別します。結果確定後の余動中も表示を維持し、次ラウンドで消えます。

## 実行

```sh
npm ci
npm run build
npm run server:beyblade
# http://127.0.0.1:8787/beyblade/ — 2つの独立したタブでオンライン対戦
```

`npm run dev`はViteの開発用。オンライン接続欄に別起動したサーバーの`ws://127.0.0.1:8787/api/beyblade`を指定します。外部公開や課金設定を自動実行するnpmスクリプトはありません。

## 検証

`npm run typecheck`、`npm run test`、`npm run build`、`npm run e2e`。追加の`npm run test:worker`は、隔離されたローカルCloudflare workerdで実際の2クライアント対戦・再起動を検証します。CIの検証結果と実際の公開先検証は別の項目です。

## 残る実測・実装課題

初版の2D/2.5D近似は廃止し、[物理モデル](physics.md)を3次元の位置・姿勢・角運動量と接触インパルスを持つ6DOF近似へ改修しました。ただし、実機との一致検証は未達です。公式の攻撃・防御・持久評価を質量や摩擦へ直接換算することはできません。質量・慣性テンソル・接触形状・ビット摩擦・歯ピッチ・実際のラチェット解放トルク・発射速度分布を測り、動画追跡から軌道・自転・傾き・フィニッシュ率を比較する必要があります。一部の正確に対応する部品の質量だけは[独立した公開秤量資料](independent-mass-observations.md)から代表値を採用しました。公式仕様でも校正保証でもなく、重心・慣性・寸法・摩擦などは引き続き推定です。公式評価を無視していた前版を改め、公式の各部品評価と形状・機構説明を、明示的な未校正の推定式で形状・慣性・接触損失・保持機構へ反映します。初期14ブレード・28ビット系統と追加の非CX一次情報を形状に反映し、未再現形状・機構は画面で明示します。大きな組立プレビューと推定値・根拠を比較でき、レール接触からXダッシュを計算します。

`npm run analyze:beyblade -- /tmp/trajectory.json` は通常の入力だけで14ケースの軌道・姿勢・エネルギー・接触イベントを記録します。レール接触を演出するための位置注入や速度倍率は使いません。

自由CX組替え、実機の変形・分離ギミック、実測CADに基づく接触・材質校正、複数公式競技形式、モード変更の実機遷移も今後の検証対象です。公開データ不足を数値の捏造で埋めません。

## 公開の安全条件

専用Worker `threejs-game-beyblade-pr7` / 専用SQLite Durable Objectのみ。既存GitHub Actionsの認証を利用し、アカウントが無料と確認できない場合は公開を止めます。有料化・新権限・本番マージ・既存本番の変更はしません。稼働状態は揮発性で、サーバー再起動時は新規セッションになります。[オンライン仕様](multiplayer.md)

通常の対応構造では、バースト時にブレード組立・ラチェット・ビットが実際の剛体として分離し、結果確定後2.5秒の余動を計算します。一体型や特殊な分離機構は未対応と明示します。[部品の質量分布と重心](center-of-mass.md)は共有形状の体積積分と推定密度から3D重心・完全な慣性テンソルを導出し、接触・回転・分離へ一貫して使用します。横偏心を人工的に加えず、対称部品の重心と外周慣性の違いを区別します。実機の測定値との一致は未検証です。

最新のレール外側への閉じ込め修正と同一入力比較は[レール回帰報告](rail-regression.md)に記録しています。初回修正は質量変更とは分けて検証し、独立質量資料の採用後にも同じ入力と外側着地条件を再検証しています。
