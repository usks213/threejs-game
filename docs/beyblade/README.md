## 実行

```sh
npm ci
npm run build
npm run server:beyblade
# http://127.0.0.1:8787/beyblade/ — 2つの独立したタブでオンライン対戦
```

`npm run dev`はViteの開発用。オンライン接続欄に別起動したサーバーの`ws://127.0.0.1:8787/api/beyblade`を指定します。外部公開や課金設定を自動実行するnpmスクリプトはありません。

## 検証

`npm run typecheck`、`npm run test`、`npm run build`、`npm run e2e`。追加の`npm run test:worker`は、隔離されたローカルCloudflare workerdで実際の2クライアント対戦・再起動を検証します。CIの検証結果と実際の公開先検証は別の項目です。

## 残る実測・実装課題

初版の2D/2.5D近似は廃止し、[物理モデル](physics.md)を3次元の位置・姿勢・角運動量と接触インパルスを持つ6DOF近似へ改修しました。ただし、実機との一致検証は未達です。公式の攻撃・防御・持久評価を質量や摩擦へ直接換算することはできません。質量・慣性テンソル・接触形状・ビット摩擦・歯ピッチ・実際のラチェット解放トルク・発射速度分布を測り、動画追跡から軌道・自転・傾き・フィニッシュ率を比較する必要があります。現在はその測定データがないため、全モデル係数は推定値です。公式評価を無視していた前版を改め、公式の各部品評価と形状・機構説明を、明示的な未校正の推定式で形状・慣性・接触損失・保持機構へ反映します。14ブレード・28ビット系統の一次情報を形状に反映し、未再現形状・機構は画面で明示します。大きな組立プレビューと推定値・根拠を比較でき、レール接触からXダッシュを計算します。

`npm run analyze:beyblade -- /tmp/trajectory.json` は通常の入力だけで14ケースの軌道・姿勢・エネルギー・接触イベントを記録します。レール接触を演出するための位置注入や速度倍率は使いません。

自由CX組替え、実機の変形・分離ギミック、実測CADに基づく接触・材質校正、複数公式競技形式、モード変更の実機遷移も今後の検証対象です。公開データ不足を数値の捏造で埋めません。

専用Worker `threejs-game-beyblade-pr7` / 専用SQLite Durable Objectのみ。既存GitHub Actionsの認証を利用し、アカウントが無料と確認できない場合は公開を止めます。有料化・新権限・本番マージ・既存本番の変更はしません。稼働状態は揮発性で、サーバー再起動時は新規セッションになります。[オンライン仕様](multiplayer.md)
