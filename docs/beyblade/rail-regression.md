# レール外側への閉じ込め：再現と物理的修正

## 公開版で再現した不具合

`df1ea55`（物理コア SHA-256 `33de174219efa3d32eb09564bb617f6856517e49c59ee1f2b3db1de4621e8bfb`）で、次の通常操作を実ブラウザーで再現しました。

- 自分：ドランソード / 3-60 / N
- CPU：ドランソード / 4-60 / T、既定シュート（パワー76%、狙い−0.12rad、傾き0.11rad）
- シュート：80% / 狙い0° / 傾き8°
- 26.45秒のシミュレーション後もCPUが右レール外側に留まり、0–0で進行。

近傍の数値監査ではCPUのCOM半径は約0.2056 m、歯列の公称半径は0.201 m。噛合状態はfalseでも平面移動がほぼ止まり、自転が続きました。これは「正当な短いレール走行」ではなく、レールを独立した柵として作った結果、外側の低い通路に着地したベイが内側へ戻れなくなる形状不備です。

別に、距離・高さだけの噛合条件が、実際には離れつつある／歯の側面が触れていない状態へ接線拘束を与える問題も見つかりました。上面・下面の固体接触と歯側面の噛合は同じではありません。

## 出典と修正の境界

[公式BX-17説明書7ページ](https://beyblade.takaratomy.co.jp/beyblade-x/manual/BX-17_manual.pdf#page=7)では、エクストリームラインは成型された外周肩部へ取り付けられています。寸法図ではないため、肩部の高さ・傾斜・遷移幅は**推定形状**です。実物の断面寸法を測定したとは主張しません。

修正では、内側の実接触側面だけを歯噛合に使い、分離時に拘束を解除します。法線と接線の有効質量を同じ接触点で連立し、引っ張る法線力を禁止。上下面や背面には通常の固体摩擦だけを使います。レールの裏側は共有の連続した肩部形状と一致する表面法線で支えます。最初の高すぎる肩部はラチェット下面へ干渉したため不採用。固定の7 mm肩部と、歯列から28 mmより外側に遅らせた外周傾斜を使い、通常のラチェット／刃の張り出し余地を残します。各ベイに合わせてスタジアムを変えません。床の位置補正は縦方向の食い込み量をそのまま法線へ掛けず、法線方向距離へ変換します。描画も同じ表面を使い、出口・復帰経路を保持します。中心への吸引、速度倍率、時間切れでの脱出、瞬間移動は使いません。

## 検証状況

同一入力の修正候補ではCPUが中心半径約0.026 mまで戻り、1.767秒でラウンドが終了します。CPUの旧い外側静止は再現せず、同ケースのtick総エネルギー増加は0、移動量の速度境界超過は最大0.0614 mmでした。実ブラウザーでも26.45秒の閉じ込めが消え、横断する軌道を確認しました。この1ケースだけで全パーツ・全入力の完全性を保証しません。

通常のSword / 3-60、80% / 0° / 8°でもF/R/GFのギア接触が残ることを確認。計算上の接触中の速度変化はそれぞれ1.260→1.545、1.271→1.417、1.273→1.740 m/sで、自転は同時に減速し、その後中心半径0.033、0.069、0.086 mまで戻ります。これは未校正モデルの再現可能な比較で、実物の測定速度ではありません。

固定コア SHA-256 は `e2d6696c9ae7d1b8b379eb4ac3fe31a5b102217f8d040d8977b75c7afaee4db5`。[8ケースの入力・イベント・数値監査](rail-comparisons.json)を保存し、通常例と以前の±50°入力を含め全例が有限状態で終了。新規レール回帰9件、描画8件、実2クライアント／ネットワーク12件が成功しました。

ダッシュ表示は、ギア衝撃の直前直後に計算した並進運動エネルギーの純増と、完全な回転運動エネルギー½L·ωの純減、内向き解放、モデル上の歯ピッチ以上の移動で判定します。正の変化だけを合算せず、重力位置エネルギーや歳差の変化を混同しません。旧30 mm閾値の置換は表示用の分類だけで、2,574固定ステップの運動状態が変更前とバイト一致することを確認しました。

補正誤差が全入力で0とは主張しません。Fの1tickに+0.279 mJ、GFで速度境界に対する最大移動超過1.324 mmが残ります（GFのエネルギー増加は0）。エネルギー上限で切り捨てて隠しません。球状先端と曲面の接触支持点にも最大約0.14 mmの近似差があり、厳密なCAD接触ではありません。

最終UI／全CIの端末結果はPRへ追記します。従来の全CI成功が、この新たな実プレイ不具合の不存在を意味しなかったことも保持します。
